## Получить проект на Windows

В обычном PowerShell, до первого запуска Claude Code в проекте:

```powershell
gh auth login
gh auth status
# Активный пользователь GitHub должен быть faf23442.
# Папка назначения должна быть новой; существующую рабочую копию не перезаписывать.
git clone --branch a/seoul-city-polish-20261104 https://github.com/KIR223/han-fists-of-seoul.git han-fists-of-seoul-city
cd han-fists-of-seoul-city
python tools/make_personal.py --role A
python tools/setup_local.py
git switch -c a/faf23442-city-00-onboarding
claude
```

Если вход в gh уже настроен на faf23442, повторный `gh auth login` не нужен. Не запускать `join.py` для этой передачи: старая таблица команды назначит B; роль A здесь явно поручена владельцем. При последующих обновлениях не перезаписывать локальные файлы роли и не отключать хуки. Для постоянной смены назначения в таблице нужна отдельная правка владельца в `o/…`, вне PR города.

Клон содержит код и данные Git. **EXE, установленная карта, `assets_bin/`, локальная библиотека и OSM из компьютера KIR223 через git clone не передаются.** Перед исправлениями выполнить этап 00 плана: сборка, инвентаризация зависимостей и получение данных. Не выдавать автоматически сгенерированную урезанную карту за ту же сцену владельца.
