# Район «Кандам» (칸담) — генератор

Вымышленный деловой район-аналог Каннама: проспект на 10 полос, башни с LED-экранами, медиаплощадь,
переулки с вывесками, столбами и проводами. Все бренды вымышленные (часть 13), машин нет.

## Сборка
Зависимости Python: `numpy`, `scipy`, `Pillow`, `lz4`. На Windows используется уже скачанный
`assets_bin/cooked/fn_noto_sans_kr/NotoSansKR.ttf`; альтернативный Noto можно указать через `KANDAM_FONT`.
Исходный Linux-путь к Noto CJK также поддерживается. Полная повторная генерация района на Windows пока не проверена;
подготовка и интеграция предоставленных GLB проверены отдельно.

```
python han/tools/pipeline/kandam/make_all.py
```
1. `fetch_cc0.py` — частичный клон GitHub-репозитория PatrickJnr/cc0-texture-pack (ambientCG, CC0) и загрузка ~70 нужных файлов
   в `assets_bin/cc0-texture-pack/` (не в Git).
2. `tex2.py` — процедурные 2K-текстуры (запасные + шум/декали) → `assets_bin/kandam/t2/`.
3. `scans.py` — PBR-материалы из сканов: декодер Source 2 `.vtex_c` (`vtex.py`: DXT1/5, BC4/5, BC7 через Pillow, LZ4-мипы),
   нормали DirectX → OpenGL, шероховатость из канала B, фасады «скан стены + процедурные окна», витрины, атлас листвы,
   фотофасады дальнего города, люки, решётки деревьев → `assets_bin/kandam/t3/`.
4. `build.py` — раскладка района и GLB (`assets_bin/kandam/out/kandam_district.glb`, ~230 МБ, ~1,5 млн треугольников, JPEG-текстуры внутри).

Переменные: `KANDAM_WORK` (рабочая папка), `HAN_CC0_PACK` (где лежит пак).

## Координаты
GLB в локальных метрах (x восток, y вверх, z юг), центр района (0, 0). В карте мира ставить со сдвигом
**(+10020, 0, +6560)** — так же заданы `bounds` в `data/world/districts/kandam.json`.

## Материалы glTF (`extras`)
`kind`: surface / facade / sign / led / lamp / foliage (alpha-mask) / glow (аддитив) / distant; `surface` — для звуков шагов.

## Готовые помещения (как в GTA V)
`interiors.py` строит 7 магазинов первого этажа вдоль проспекта, в которые можно зайти через открытый дверной проём:
одежда (манекены, стойки, стол со стопками, полки, примерочные, касса), 분식집 (ванны с теокпокки и одэном, кимбап,
световое меню, столы из нержавейки и красные табуреты, холодильник), 편의점 (острова стеллажей с товаром, стена холодильников,
касса, стойка с рамёнами), кафе (подвесные лампы, столики, бар, кофемашина, витрина с десертами, меню-доска, растения),
косметика (стеллажи, тестеры, зеркала). Помещения — в отдельном `kandam_interiors.glb` (стримится при подходе к двери),
витрины с прозрачным стеклом — в основном GLB; `interiors.json` — тип, дверь, площадь пола и высота каждого помещения.
Материалы помещений `extras.kind = "interior"` (свой свет, не зависит от солнца), стекло — `"glass"` (alpha blend).

## Состав
- `facade3d.py`: объёмные фасады вилл, малоэтажек и офистелей — утопленные окна (откосы, рама, импосты, отлив), закрытые остеклённые
  балконы-выступы с бельём и растениями внутри, корзины кондиционеров, решётки на окнах, межэтажные пояса, венчающий карниз,
  офисное ленточное остекление с ламелями; атлас интерьеров окон (шторы, жалюзи, комнаты, офисы, балконы) с ночной подсветкой;
- деревья `trees.py`: гинкго (72 %) и дзелква — ствол, ярусы веток, веточки, карточки листвы на концах веток (тени с альфа-тестом);
- `korea_props.py`: решётки приствольных лунок, болларды, жёлтая тактильная плитка (점자블록), люки, кондиционеры на стенах и крышах,
  баки воды на крышах, бетонные столбы с проводами, палатки-포장마차; зелёные крыши;
- просмотр/скриншоты: `viewer.html` + `shoot.js` (WebGL2-рендер для превью, не движок): `node shoot.js shots_full.json 1920 1080`.
