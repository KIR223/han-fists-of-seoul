# Бокс и общие движения манекена

Локальная реализация поверх main `dad9a79f`: один стиль, белый мужской манекен
Quaternius CC0 1,80 м, 65 костей с пальцами, 104 клипа. Бинарные ассеты находятся
в игнорируемом `assets_bin/`; в Git остаются источники, хэши и скрипты.

## Запуск и воспроизведение

1. Установить Blender 4.3, Python 3 и инструменты сборки проекта.
2. Из корня: `python han/anim/tools/build_boxing.py --blender path/to/blender`.
   Скрипт получает бесплатные Standard UAL1/UAL2, сверяет SHA256/CC0,
   создаёт `Boxing.blend`, уточняет контакты, проверяет геометрию и экспортирует
   `assets_bin/cooked/quaternius_ual/Boxing.hchar`. Ошибка Blender останавливает сборку.
3. Собрать проект существующим пресетом, например `windows-release` или
   `vs2022-release`; CMake подключит закреплённый ozz 0.16.
4. `han_arena_demo --foes 1` — дуэль; `--auto --foes 4` — групповой smoke.
   `han_player_demo` — WASD, мышь, Shift, Space, камера с коллизией.
5. Для отдельного движения: `han_arena_demo --animation-preview Boxing_DempseyRoll`.
   `--capture-dir folder --frames 90 --deterministic --no-ui --no-capture`
   сохраняет последовательность PNG. Это воспроизведение клипа с фиксированной
   камерой, боевую симуляцию оно не оценивает.

Если HCH1 отсутствует, арена сообщает о возврате к старым примитивам.
`--primitives` включает их явно. Бойцы используют общий mesh/клипы и независимые
sampling context/палитры; skinning одинаковый в цвете и тенях.

## Управление боксом

| Ввод | Действие |
|---|---|
| ЛКМ по ритму | Джеб → кросс → левый хук → передний апперкот |
| A/D + ЛКМ | Левый/правый хук |
| S + ЛКМ | Джеб с отходом |
| ПКМ + ЛКМ | Джеб по корпусу |
| ПКМ + A/D + ЛКМ | Хук в печень / апперкот по корпусу |
| Alt + ЛКМ | Задний апперкот |
| Shift + W + ЛКМ | Двойной джеб с шагом |
| Shift + A + ЛКМ | Хук с пивотом |
| Удерживать ЛКМ | Overhand |
| R / R+S / R+D | Dempsey / печёночный нокаут / bolo; нужен фокус |
| ПКМ | Блок; точное нажатие — парирование |
| Space + направление | Уклон с учётом летящего удара |
| C | Нырок |
| Q + A/D | Шолдер-ролл |
| ЛКМ после уклона / отхода / нырка | Slip counter / pull counter / duck hook |
| E вблизи | Клинч; защита/удар разрывает, есть автоматический таймаут |
| Enter | Перезапуск арены |

## Что реализовано

- Все 19 ударных техник имеют отдельный клип; двадцатое действие — клинч.
  В двойном джебе два контакта, в Dempsey три, с отдельной рукой/кадром и долей
  общего урона. Промах первой руки не переносится на следующий контакт.
- Контакты совмещены со startup/active/recovery, hitstop замораживает позу.
  IK ударной руки направлен к высоте головы/корпуса соперника и ограничен длиной
  костей. Анимация не начисляет урон — это делает CombatSim.
- Восемь направлений shuffle: фаза по пройденному расстоянию, сгиб коленей,
  удержание опорной стопы в авторском клипе. Во время удара маска ног смешивает
  футворк отдельно, сохраняя вращение корпуса и движение рук удара.
- Реакции различаются по зоне/стороне/печёночному попаданию. Четыре направления
  падения фиксируются при нокдауне, поза удерживается до настоящего подъёма.
  Подъём из UAL2 LayToIdle идёт вперёд через опору рукой/коленом, занимает 168
  кадров симуляции. Начальная геометрия подъёма совпадает с концом падения.
- Клинч связывает обоих бойцов, восстанавливает выносливость, заканчивается
  вводом, таймаутом или попаданием третьего. Официальные правила включены в арене
  по умолчанию: лежачего не бьют. Для уличного режима есть `--street`.
- Общие idle/walk/jog/sprint/jump start/loop/land работают в player_demo
  от скорости, grounded и вертикальной скорости физического контроллера.

## Проверки и границы

`check_boxing.py` проверяет деформированную поверхность: падение→подъём без скачка,
пол, ширину стойки и опорную ногу восьми направлений. Уточнение root-кривой и
экспорт падений идут на 240 Гц, прочих авторских движений — на 60 Гц. Отчёт:
`Boxing.contact-check.json`. Четыре набора CTest проверяют загрузку/скиннинг,
IK, маску, контакты, клинч, правила, доступность всех действий и переходы прыжка.
Для реального ассета задать `HAN_CHARACTER_ASSET` абсолютным путём к HCH1.
`tests/animation/check_arena.py --exe path/to/han_arena_demo --require-validation`
проверяет живой Vulkan, validation и отсутствие чёрного кадра.

Это аниматорские ключи и IK на CC0-исходниках, без motion capture. Падения
проверены на ровном полу; это не active ragdoll, адаптирующий тело к ступеням,
стенам и другому бойцу. Такой физический слой — этапы P2/P3, runtime IK стоп
на рельефе — A3. Редактор/граф/root motion и игровые экраны мини-игр остаются
отдельными пунктами DoD A1/G2. Windows/RTX 2050 и ощущения от ручного ввода
нужно проверить на целевом компьютере; Linux llvmpipe не даёт его бюджет FPS.

Лицензии и ссылки на UAL1/UAL2/ozz: `docs/credits/A.md`, `docs/credits/B.md`.
Mixamo и платные пакеты не нужны. Данные поз и маркеров находятся в
`data/combat/boxing_animation.json`, привязок — в `boxing_visuals.json`, общих
переходов — в `common_visuals.json`.
