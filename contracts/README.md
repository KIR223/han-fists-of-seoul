# contracts/ — общие интерфейсы между зонами

Здесь лежит всё, через что зоны A и B обращаются друг к другу: заголовки C++, схемы JSON, форматы данных.
Правила — `docs/team/CONTRACTS.md`. Коротко:

- Папка общая (`shared`): править может любой, но только отдельным маленьким PR с меткой `contract` и описанием «зачем / кого затронет».
  Одобряют все потребители (CODEOWNERS).
- Одна сущность — один файл. Логики нет, только типы, интерфейсы, комментарий и пример вызова.
- Заглушки — в `stubs/`. Схемы данных — в `schemas/`. Заявки на строки локализации — в `loc_requests/<роль>.csv`.
- Каждый контракт записан в `registry.md` (поставщик, потребители, статус, версия).

Контракты v1 создаёт A в этапе E0 (список — в `docs/team/CONTRACTS.md`), схемы данных — их владельцы (B: приёмы, профили, сюжет, локализация; A: мир).
