## Часть 53. Дополнительные идеи, которые делают игру особенной

> То, чего обычно нет в играх жанра, но что усиливает историю, вайб и желание вернуться. Всё — по этапам, после вертикального среза.

| Идея | Как работает |
|---|---|
| Дневник Тэхо | каждый игровой вечер герой пишет 2–3 строки о дне (генерируются из шаблонов по событиям: с кем дрался, что ел, кому помог); читается в телефоне; в финале — «книга года» |
| Письма маме | раз в неделю — голосовое сообщение маме: игрок выбирает, что рассказать (правду или «всё хорошо»); её ответы меняются по сюжету |
| Карта воспоминаний | на карте отмечаются места важных моментов (первая победа, крыша, пожар); вернуться и «вспомнить» — короткая сцена |
| Фотоальбом | лучшие фото и фото-полоски из фотобудок с друзьями, автоматически по сюжету и вручную |
| Свой тег | редактор граффити-подписи (простые формы и цвета); тег появляется в местах побед и на стенах освобождённых районов |
| Кассеты-плейлист | найденные музыкальные кассеты добавляются в плейлист плеера героя (наушники и машина) |
| Настроение героя | лёгкий скрытый параметр: еда, сон, друзья, животные, вайб-места поднимают; поражения и одиночество — опускают; влияет на мелочи (походка, реплики, бонус Фокуса) |
| Сны | в особые ночи (после пожара, перед финалом) — короткие сюрреалистичные сны: море Мокпхо, отец, ринг 1988 |
| Дорама на ТВ | вымышленный сериал идёт по ТВ эпизодами; его сюжет перекликается с историей героя |
| Шоу «Король улиц» | телешоу, где появляются ролики героя; рейтинг шоу растёт вместе с его славой |
| Лига залов | зал Пака выставляет команду учеников против других залов: менеджмент, тренировки, бои |
| Школа Тэхо | пост-игра: герой сам ведёт классы для новичков (мини-игры в роли тренера, свои ученики) |
| Уличный армрестлинг | турниры у пхочжанмача и на рынках, своя таблица |
| Падук в парке | упрощённая игра в падук со стариками, рейтинг игрока |
| Последний поезд | ночью можно проехать весь круг линии 2 и смотреть город — достижение «Круг» |
| Проводник туристов | подработка: провести туристов по маршруту и рассказать о местах (выбор фактов) |
| Курьерская лига | ночные гонки курьеров с сезонной таблицей |
| Ночные сходки | встречи тюнинга у реки: показать машину, голосование, вызовы |
| Тогда и сейчас | фото-маршруты фотографа-ветерана: старое фото места и современный вид |
| Погода в эфире | в дождь и снег донаты за «бой под дождём» выше; публика в эфире реагирует на погоду |
| Свой ремонт | зал Пака после пожара можно украшать: плакаты, цвета, тренажёры, трофеи учеников |
| Сезонные события | Хэллоуин в Итэвоне, Рождество в Мёндоне, фейерверки, фестиваль фонарей — с уникальными заданиями, одеждой и вызовами |
| Режим «Город просыпается» | встать в 5 утра и пройти утренний маршрут Пака — бег, рынок, первый автобус |
| Музыкальные сцены | бускеры исполняют оригинальные песни радио; у некоторых можно купить «альбом» для плеера |
| Честный магазин | без микротранзакций, лутбоксов и платных ускорений — всё зарабатывается игрой |
| Пасхалки | отсылки к жанру и корейской поп-культуре без нарушения прав: только намёки, без имён и логотипов |
