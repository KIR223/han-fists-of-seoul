## Часть 68. Стандарты кода

- C++20, без RTTI в движке (по возможности), исключения только в инструментах; clang-format и clang-tidy.
- PascalCase для типов, camelCase для функций и переменных, m_ для членов, k для констант; пространства имён han:: и game::.
- Модули зависят только «вниз»: game → han, han не знает о game.
- Никаких глобальных синглтонов, кроме перечисленных в ARCHITECTURE.md сервисов.
- Баланс и настройки — в данных (JSON / Lua), не в коде.
- CMake Presets (debug, dev, release), /W4, предупреждения = ошибки в проверочной сборке.
- Перед завершением этапа: сборка без предупреждений, тесты зелёные, ноль ошибок валидации Vulkan, бенчмарк в бюджете, PROGRESS.md и ARCHITECTURE.md обновлены.
