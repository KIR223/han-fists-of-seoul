## Часть 42. Озвучка

> Основной язык игры и озвучки — **русский**. Все сюжетные персонажи говорят по-русски. На улицах Сеула прохожие часто говорят **по-корейски** (с субтитрами) — это создаёт ощущение, что ты действительно в Корее.


### 42.1. Языковая схема

| Что звучит | Язык | Почему |
|---|---|---|
| Сюжетные сцены, телефон, миссии | русский (полная озвучка) | главная история должна восприниматься без чтения |
| Друзья, мастера, торговцы, к которым обращается герой | русский | диалоги с игроком |
| Прохожие между собой, толпа, продавцы-зазывалы, полиция в рации | корейский (около 60%) + русский (40%) | атмосфера: город живёт своей жизнью; русские реплики — чтобы игрок понимал реакции на себя |
| Приветствия и вежливые фразы | корейский | «어서 오세요», «감사합니다», «죄송합니다» — фирменный звук Сеула |
| Радио и ТВ | русский (ведущие) + корейский (реклама, джинглы) | смесь, как в многоязычном городе |
| Объявления метро, светофоры, навигатор | корейский + русский дубль (как в реальном метро — корейский и английский) | достоверность |
| Выдохи, выкрики, стоны в бою | без языка | универсально |

В настройках: «Корейские реплики прохожих: часто / иногда / только русский». Опционально позже — полная корейская озвучка сюжета как второй язык.


### 42.2. Откуда голоса

| Вариант | Как |
|---|---|
| **A. Бесплатный синтез речи** — основной | открытые модели TTS, у которых и код, и веса под разрешительной лицензией (MIT / Apache 2.0), запускаются локально на компьютере владельца бесплатно; или бесплатные тарифы сервисов **только если** их условия разрешают коммерческое использование результата. Голоса — созданные «с нуля», **без клонирования реальных людей** |
| **B. Друзья-добровольцы** | знакомые записывают реплики дома (крики, плач, смех, ключевые эмоции) и подписывают простое согласие на бесплатную передачу прав на запись для игры |
| **C. Гибрид** (рекомендуется) | основной объём — синтез; самые эмоциональные реплики ключевых персонажей — добровольцы; корейские реплики улиц — синтез, проверенный носителем языка |

- Всегда: голос не похож на конкретную знаменитость; согласия и лицензии хранятся в VOICE_RIGHTS.md; использование ИИ отмечается в анкете Steam.
- Для эмоций (крик, плач, смех, шёпот) синтез часто звучит хуже — эти реплики приоритетно записываются живьём.


### 42.3. Конвейер озвучки

1. Сценарий в файлах локализации: у каждой реплики — ключ, персонаж, эмоция (из списка 12), громкость (шёпот / обычно / крик), контекст (катсцена, телефон, бой, улица), длительность-ограничение.
2. **han_vo**: генерирует черновую озвучку синтезом для всех реплик (чтобы сразу играть с голосом), складывает в vo/draft/.
3. Владелец прослушивает в игре и помечает реплики: «ок», «перегенерировать», «на живую запись».
4. Финальные файлы заменяют черновые без изменения кода — по ключам.
5. Автоматически: нормализация громкости, обрезка тишины, фильтры (телефон, рация, радио, мегафон), разметка фонем для синхронизации губ.


### 42.4. Технические требования

| Параметр | Значение |
|---|---|
| Формат записи | WAV 48 кГц / 24 бит, моно, без сжатия; в игре — Opus или Ogg Vorbis |
| Громкость | диалоги нормализуются около −23 LUFS, пики не выше −3 dBTP |
| Шумы | фон тише −60 dB; без реверберации комнаты (реверберация добавляется в игре по зоне) |
| Имена файлов | ключ_реплики_язык.wav, например m045_park_012_ru.wav |
| Хранение | исходники отдельно от игровых файлов, бэкап |

### 42.7. Реплики толпы и боя (barks)

- Каждая ситуация (увидел драку, толкнули, дождь начался, узнал героя, машина чуть не сбила, похвалил одежду…) имеет 10–30 вариантов на голос.
- Правила: не повторять одну реплику одного NPC чаще раза в 10 минут; приоритеты (опасность > реакция на героя > болтовня); не больше 3 одновременных голосов рядом; громкость по дистанции.
- Корейские реплики показываются в субтитрах по-русски с пометкой языка мелким серым шрифтом (опция).


### 42.8. Корейские фразы улиц (образцы)

| Фраза | Чтение | Когда |
|---|---|---|
| 어서 오세요! | осо осеё | вход в магазин или ресторан — «Добро пожаловать!» |
| 감사합니다 | камсамнида | благодарность продавца |
| 죄송합니다 | чесонхамнида | толкнули, извиняются |
| 아이고! | айго | удивление, усталость, сочувствие — у пожилых |
| 대박! | тэбак | «Офигеть!» — молодёжь при виде трюка или драки |
| 뭐야?! | мвоя | «Что такое?!» — испуг, возмущение |
| 조심해! | чосимхэ | «Осторожно!» |
| 경찰 불러! | кёнчхаль пурро | «Зовите полицию!» |
| 사진 찍어도 돼요? | саджин ччигодо твэё | «Можно сфотографироваться?» — фанаты |
| 화이팅! | хваитин | «Давай! Вперёд!» — поддержка |
| 맛있어요 | масиссоё | «Вкусно» — за столиками кафе |
| 빨리빨리! | ппалли-ппалли | «Быстрей-быстрей!» — курьеры, торговцы |
| 비 온다 | пи онда | «Дождь идёт» |
| 택시! | тхэкси | ловят такси ночью |
| 어디 가? | оди ка | «Куда идёшь?» — друзья |

Список расширяется до 300+ фраз; тексты проверяются носителем языка (или минимум — двумя независимыми переводчиками), чтобы не было ошибок и грубостей по незнанию.


### 42.9. Микширование

- Диалог всегда слышен: музыка и радио приглушаются (ducking) на 6–9 dB во время реплик.
- Реплики по телефону — фильтр телефона; рация полиции — фильтр рации с шумом; мегафон — искажение.
- Реверберация по зоне: переулок, тоннель, зал, метро, клуб, баня.
- Шёпот и крик звучат по-разному не только громкостью: разные записи.
