## Часть 52. Авторские права и выпуск в Steam без проблем

> Цель — чтобы игру можно было спокойно продавать в Steam и в будущем не получить претензий. Этот раздел — чек-лист, а не юридическая консультация: перед релизом владельцу стоит показать его юристу.


### 52.1. Принцип

**Всё, что есть в игре, либо создано для игры, либо взято по лицензии, разрешающей коммерческое использование, и записано в CREDITS.md с доказательством лицензии.** Если происхождение ассета неясно — он удаляется.


### 52.2. Чек-лист по видам контента

| Контент | Правило |
|---|---|
| Код | свой + библиотеки с разрешительными лицензиями (MIT, BSD, zlib, Apache 2.0); тексты лицензий — в папке licenses/ и в окне «Лицензии» в меню; GPL-код в игру не включать (Blender и BlenderGIS — только инструменты) |
| 3D-модели и текстуры | только бесплатные: CC0, CC-BY (с указанием авторства) или сделанные Claude; для каждого — ссылка, автор, лицензия, дата скачивания, скриншот страницы лицензии |
| Анимации | то же; проверить, что лицензия mocap-паков разрешает использование в своём движке |
| Шрифты | только SIL Open Font License или аналогичные (Noto Sans, Noto Sans KR, Black Han Sans); тексты лицензий в игре |
| Музыка | только CC0, CC-BY или своя (сделанная в LMMS из CC0-сэмплов); **никаких настоящих песен K-pop и других исполнителей**; для режима стримеров — отметить треки, безопасные для трансляций |
| Звуки | CC0 / CC-BY; записи, сделанные самим владельцем |
| Голоса | бесплатный синтез речи с разрешительной лицензией или друзья-добровольцы с письменным согласием (см. «Озвучка») |
| Тексты | все диалоги, песни радио, названия, реклама — оригинальные |
| Бренды | все марки машин, магазины, напитки, приложения, телеканалы, банки — вымышленные; логотипы — свои; никаких похожих до степени смешения названий и цветов известных брендов |
| Реальные люди | ни одного реального человека, айдола, спортсмена, политика, стримера — ни по имени, ни по узнаваемой внешности или голосу |
| Реальные места | названия районов, улиц, станций, рек и гор — можно; современные узнаваемые здания и уличные скульптуры — **стилизованно и под вымышленными названиями** (в Корее свобода панорамы ограничена: закон делает исключение для воспроизведения ради продажи копий); исторические дворцы и храмы — можно воспроизводить, но тоже без точного копирования современных реставрационных деталей с фото |
| Символика | без государственной символики в сомнительном контексте, без реальной полицейской эмблемы (своя стилизованная), без символов реальных партий и религиозных организаций |
| Карта | данные OSM — с указанием «© участники OpenStreetMap» (ODbL); прочие открытые данные — по их лицензиям; никаких 3D-тайлов картографических сервисов |
| Фото-референсы | только как референс; в игру не попадают без лицензии |
| Нейросети | разрешено как инструмент, но: только сервисы и модели с коммерческой лицензией; результат проверяется на сходство с чужими работами; в Steam заполняется раскрытие использования ИИ |


### 52.3. Раскрытие ИИ в Steam

- С января 2024 года Steam требует в анкете содержания указывать, что игра использует контент, созданный ИИ: **заранее сгенерированный** (картинки, голоса, тексты, сделанные при разработке) и **генерируемый во время игры**. Описание попадает на страницу игры.
- Разработчик отвечает за то, что такой контент не нарушает чужих прав; для генерации во время игры — нужны меры, не допускающие незаконного контента.
- В этой игре по умолчанию ИИ-контента во время игры нет (чат стрима и реплики — из заготовленных шаблонов). Если используется синтез речи или нейросетевые модели при разработке — отметить в анкете и описать.


### 52.4. Документы проекта

- **CREDITS.md** — каждый внешний ассет: что, откуда, автор, лицензия, ссылка, дата, где используется.
- **licenses/** — копии всех лицензий и чеков о покупке.
- **VOICE_RIGHTS.md** — согласия добровольцев, лицензии моделей синтеза речи, имена голосов, даты.
- **AI_USAGE.md** — где и какие ИИ-инструменты использовались (для анкеты Steam).
- Скрипт **han_licenses**: собирает титры и окно «Лицензии» из CREDITS.md, падает с ошибкой, если у ассета в игре нет записи о лицензии (проверка перед каждой релизной сборкой).


### 52.5. Содержание и рейтинг

Игра строго 18+ — подробно в части «Игра строго 18+»: кровь, травмы, жестокие добивания, мат, алкоголь; без сексуального контента, без насилия над детьми и животными, без микротранзакций и лутбоксов, без азартных игр на реальные деньги. Анкета содержания Steam заполняется честно; для отдельных стран — требования их рейтинговых органов.
