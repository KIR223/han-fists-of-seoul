## Часть 50. Память и производительность: подробные бюджеты

> Цель: на ноутбуке с RTX 2050 (4 ГБ), 4–6-ядерным процессором и **14–16 ГБ ОЗУ** игра идёт стабильно **не впритык**: остаётся запас для Windows, браузера и Discord.


### 50.1. Оперативная память (ОЗУ)

| Подсистема | Средне | Высоко | Примечание |
|---|---|---|---|
| Ячейки мира (объекты, навмеш, трафик) | 1,8 ГБ | 2,4 ГБ | по радиусу стриминга |
| Меши (CPU-копии для физики и анимации) | 0,6 ГБ | 0,8 ГБ | GPU-копии — в VRAM |
| Анимации и база motion matching | 0,6 ГБ | 0,7 ГБ | сжатие ozz |
| Звук | 0,4 ГБ | 0,5 ГБ | музыка и радио стримятся с диска |
| Физика | 0,4 ГБ | 0,6 ГБ | Jolt + обломки + ткань |
| ИИ, толпа, трафик | 0,3 ГБ | 0,4 ГБ |  |
| Скрипты, данные, сохранение | 0,2 ГБ | 0,2 ГБ |  |
| Интерфейс и шрифты | 0,2 ГБ | 0,2 ГБ | атласы хангыля |
| Буферы стриминга и загрузки | 0,8 ГБ | 1,0 ГБ | кольцевые буферы |
| Драйвер, Vulkan, прочее | 0,8 ГБ | 1,0 ГБ |  |
| **Итого игра** | **≈ 6,1 ГБ** | **≈ 7,8 ГБ** | потолок: 7 / 9 ГБ |

- На системе с 16 ГБ после Windows (≈ 3–4 ГБ) и браузера (≈ 1–2 ГБ) остаётся ≥ 3 ГБ запаса на «Средне».
- Тест утечек: 3 часа игры с автопилотом по городу — рост памяти не более 100 МБ.
- Никаких пиков при загрузке ячеек: загрузка по кускам, освобождение до загрузки следующего.

### 50.3. Процессор

| Система | Бюджет на кадр (мс) | Как держать |
|---|---|---|
| Игровая логика и бой | 1,5 | фиксированный шаг 60 Гц |
| Физика | 3–5 | job system, Physics LOD |
| Анимация | 2 | LOD анимации, параллельно |
| ИИ, толпа, трафик | 2 | пониженная частота тиков вдали |
| Стриминг и декомпрессия | фон | отдельные потоки, не на главном |
| Подготовка рендера | 2 | GPU-driven отсечение, мало draw calls |
| Скрипты Lua | 0,5 | без тяжёлых циклов в кадре |
| **Главный поток итого** | ≤ 12 | 60 FPS с запасом |


### 50.4. Диск и загрузки

- Размер установки — цель **до 45 ГБ** (с областью вокруг города) (сжатые текстуры, звук в Ogg/Opus, архивы с быстрым доступом).
- SSD рекомендован; на HDD игра запускается, но с более редким стримингом и упрощением дальних ячеек.
- Первая загрузка — до 20 с на SSD; загрузка сохранения — до 15 с; выход из интерьера — без загрузки.
