## Часть 76. Ассеты из интернета: найти, проверить, переделать

> Да: модели, текстуры, звуки и анимации **можно и нужно искать в интернете и переделывать под игру** — это основной путь при трёх разработчиках. Но только то, что **по лицензии** разрешает коммерческое использование, изменение и распространение в составе игры. Всё остальное — нельзя, даже если «все так делают». Эта часть уточняет «Ассеты: источники и учёт лицензий» и «Главное правило: всё бесплатно и юридически чисто».


### 76.1. Какие лицензии можно

| Лицензия | Можно? | Условия |
|---|---|---|
| CC0, общественное достояние | да | ничего не нужно; записать источник всё равно |
| CC-BY (любая версия) | да | указать автора в титрах и **отметить, что ассет изменён** (колонка «Изменён?» в docs/credits) |
| MIT, BSD, Apache 2.0, zlib | да | для инструментов и части ассетов; сохранить текст лицензии |
| SIL OFL (шрифты) | да | шрифт нельзя продавать отдельно; в игре — можно |
| Корейская «공공누리» тип 1 | да | указание источника; типы 2, 3, 4 — нельзя (запрет коммерции или изменений) |
| CC-BY-SA | только с одобрения владельца | изменённый ассет придётся распространять под той же лицензией — для ключевых ассетов избегать |
| «Royalty Free» площадок (BlenderKit, CGTrader и т. п.) | только с одобрения владельца | читать текст: разрешено ли встраивание в игру; ассет не должен извлекаться как отдельный продукт |
| CC-BY-NC, CC-BY-ND, «Editorial», «Personal use» | нет | некоммерческие, без изменений, только для новостей или личного пользования |
| Без лицензии («нашёл на форуме», «free download») | нет | нет лицензии = нельзя |
| Рипы из игр, фильмов, дорам | нет | никогда, даже как временная заглушка |
| Ассеты только для другого движка (Megascans, MetaHuman, магазины ассетов движков) | нет | по правилу проекта |
| Карты, панорамы и 3D-тайлы картографических сервисов, скриншоты | нет | условия сервисов запрещают; только как зрительный референс |


### 76.2. Где искать

| Источник | Что | Лицензия | Как искать |
|---|---|---|---|
| Poly Haven | текстуры, HDRI, модели | CC0 | всё можно |
| ambientCG | текстуры, материалы | CC0 | всё можно |
| cgbookcase, ShareTextures | текстуры | CC0 | проверить страницу ассета |
| Quaternius, Kenney | лоу-поли модели, киты, UI, звуки | CC0 | для заглушек и пропсов |
| Sketchfab | модели всего (ханоки, улицы Кореи, пропсы, машины) | разная | фильтр «Downloadable» + лицензия CC0 или CC-BY; читать карточку; без логотипов |
| Poly Pizza | лоу-поли модели | CC0 / CC-BY | проверить у каждой модели |
| OpenGameArt | модели, текстуры, звуки, музыка | разная | только CC0 / CC-BY / OFL, проверять каждый файл |
| Smithsonian Open Access и музеи | сканы предметов | часто CC0 | отмечено на странице объекта |
| Wikimedia Commons | фото, узоры, карты | разная | как текстура — только CC0 / CC-BY / PD; иначе — только референс |
| Корейские открытые порталы (культура, музеи, наследие) | фото, узоры, иногда 3D | 공공누리 тип 1–4 | брать только тип 1 (значок на странице) |
| Freesound | звуки | CC0 / CC-BY / NC | фильтр: только CC0 и CC-BY |
| Mixamo | анимации, персонажи | свои условия Adobe | в игре можно; исходники не распространять (см. «Анимация высокого уровня») |
| Google Fonts, Naver (шрифты Nanum) | шрифты с хангылем | OFL | Noto Sans KR, Nanum, Black Han Sans, Do Hyeon |
| OpenStreetMap, SRTM, Copernicus DEM | карта и рельеф | ODbL / PD / свободная с атрибуцией | см. «Карта: размер, источники, построение» |


### 76.3. Как Claude ищет ассеты

1. Берёт задачу из ASSETS_TODO.md своей зоны (что нужно, бюджет, стиль, приоритет).
2. Ищет в интернете сам (веб-поиск) по списку источников выше; запросы на английском и корейском: «hanok 3d model CC0», «korean street props», «한옥 3D 모델 무료», «korean apartment building model», «temple dancheong pattern CC0», «rice paddy texture».
3. Составляет короткий список из 3–5 кандидатов и оценивает по 7 признакам: лицензия, полигоны, топология, развёртка UV, PBR-текстуры, совпадение со стилем, масштаб и реализм.
4. Записывает выбранный ассет в манифест (han_fetch): ссылка, автор, лицензия, ссылка на текст лицензии, дата, контрольная сумма. Скачивает только через han_fetch.
5. Сомнительная лицензия → Issue с меткой legal владельцу; до ответа ассет не используется.


### 76.4. Конвейер переделки (автоматический, скриптами Blender)

| № | Шаг | Что делается |
|---|---|---|
| 1 | Импорт и нормализация | метры, оси (+Y вверх), пивот по стандарту, удаление скрытых и лишних объектов, исправление нормалей |
| 2 | Оптимизация сетки | упрощение до бюджета (см. «Каталог моделей и ассетов»), ретопология для героев-ассетов, слияние материалов (≤ 2 для пропса) |
| 3 | Развёртка и запекание | новая UV с правильной плотностью текселей, запекание нормалей с высокополигональной версии, AO |
| 4 | Новые текстуры | замена на материалы библиотеки проекта (см. «Текстуры и материалы всей карты»), подгонка цвета, маски износа |
| 5 | «Корёизация» | замена деталей на корейские: вывески → якоря для текста движка на хангыле, кондиционеры, решётки, газовые счётчики, номера корпусов, крыши, разметка |
| 6 | Чистка брендов | удаление любых логотипов, надписей и узнаваемых форм марок; замена на бренды пародийной вселенной |
| 7 | LOD, коллизии, импостеры | LOD1–3 (meshoptimizer), простые коллизии (выпуклые оболочки), импостер для дальних объектов |
| 8 | Готовка | han_cooker: KTX2/BC-сжатие, бинарный формат, горячая перезагрузка |
| 9 | Проверка | скриншоты в движке при дне, ночи и дожде рядом с референсом; бюджет полигонов и памяти; проверка повтора текстур |
| 10 | Учёт | строка в docs/credits/<роль>.md: ассет, автор, ссылка, лицензия, где используется, «Изменён: да — что сделано» |


### 76.5. Примеры переделки

| Исходник (свободная лицензия) | Что делаем | Результат |
|---|---|---|
| Американская заправка | новый навес в цветах вымышленной сети, колонки для газа такси, вывеска мойки, корейская разметка | корейская АЗС на трассе |
| Европейский сельский домик | цветная металлическая крыша, побелка, кувшины для соусов во дворе, зелёные ворота, тарелка | дом корейской деревни |
| Японский храм | **осторожно**: другая кривизна крыши, другие цвета; переделать крышу, роспись танчхон вместо красного лака, корейские ворота | корейский горный храм (или отказ — собрать из своего кита) |
| Китайская пагода | каменная корейская пагода проще — лучше своя модель по референсу | своя пагода |
| Склад из промышленного кита | корейские надписи текстом движка, синие ворота, контейнеры вокруг | склад порта Ыйхан |
| Машина без лицензии на марку | переделка решётки, фар, удаление шильдиков, вымышленная марка, корейский номер | модель вымышленной марки (см. «Транспорт как в GTA») |
| Скан камня CC0 | тонировка под светлый корейский гранит, лишайник маской | гранит массива Пукхансан |


### 76.6. Культурная точность: Корея, а не «вообще Азия»

| Деталь | Как правильно в Корее |
|---|---|
| Крыши храмов и ханоков | плавная кривизна с поднятыми углами, серая черепица; роспись танчхон в зелёно-синих тонах с красным, а не сплошной красный лак |
| Надписи | хангыль (иногда английский); иероглифы — только на старых табличках храмов и дворцов |
| Дороги | жёлтая двойная осевая, синие автобусные полосы, «зебры» с жёлтыми зонами ожидания у переходов, светофоры горизонтальные с 3–4 секциями |
| Столбы и провода | бетонные столбы с плотными пучками проводов и табличками; трансформаторы на столбах |
| Номерные знаки | корейский формат (цифры + слог хангыля + цифры), вымышленные сочетания |
| Еда и посуда | металлические палочки и ложки, металлические миски для риса, зелёные бутылки (вымышленная марка) |
| Дома | цветные крыши деревень, красный кирпич вилл, номера корпусов «105동» на башнях |
| Одежда стариков | яркие походные куртки, козырьки, рабочие штаны с цветочным узором у бабушек |


### 76.7. Кто что делает

- Каждая роль ищет и переделывает ассеты **своей зоны** (A — мир, здания, пропсы улиц, транспорт, рельеф, материалы, прохожие; B — герой и бойцы, анимации, залы, интерьеры миссий, интерфейс, звуки и музыка).
- A делает и поддерживает инструменты конвейера (han_fetch, han_cooker, скрипты Blender, проверка лицензий).
- Владелец одобряет сомнительные лицензии (метка legal) и проводит юридическую проверку перед релизом (этап E15).
- Проверка CI не пропускает новый ассет без строки в docs/credits со свободной лицензией.
