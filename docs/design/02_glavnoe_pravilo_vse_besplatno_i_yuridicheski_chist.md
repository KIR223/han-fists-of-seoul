## Часть 2. Главное правило: всё бесплатно и юридически чисто

> **Это указание для всего проекта.** Каждый ассет, инструмент, библиотека, шрифт, звук, голос и сервис должен быть **бесплатным** и при этом **разрешать коммерческое использование** в продаваемой игре. Всё, что может создать юридические проблемы, — не используется вообще. Все названия брендов, компаний, продуктов, людей и современных зданий — **вымышленные, в духе Rockstar** (см. «Пародийная вселенная»). Если ты (Claude) сомневаешься в лицензии — не используй и предложи бесплатную замену или сделай сам.


### 2.1. Разрешённые лицензии

| Лицензия | Можно? | Условие |
|---|---|---|
| CC0 / общественное достояние | да | ничего не требуется (но записываем источник) |
| CC-BY 3.0 / 4.0 | да | указать автора и лицензию в титрах и CREDITS.md |
| SIL Open Font License (OFL) | да (шрифты) | приложить текст лицензии, не продавать шрифт отдельно |
| MIT, BSD, zlib, Apache 2.0, Boost | да (код) | приложить тексты лицензий в папке licenses/ |
| Лицензия Poly Haven, ambientCG, Kenney, Quaternius | да | это CC0 — проверить на странице каждого ассета |
| Mixamo (бесплатно с аккаунтом Adobe) | да, с ограничениями | анимации и персонажи можно использовать в коммерческих играх без роялти, но нельзя распространять исходные файлы как ассеты; перепроверить условия на сайте |
| CMU Motion Capture Database | да, с ограничениями | можно включать в продаваемые продукты, нельзя перепродавать сами данные; перепроверить формулировку на сайте |
| ODbL (OpenStreetMap) | да (данные карты) | указать «© участники OpenStreetMap»; соблюдать условия производной базы |
| Лицензия Pixabay | осторожно | разрешает коммерческое использование, но есть ограничения; использовать только если нет CC0-аналога, проверить каждый файл |


### 2.2. Запрещённые источники

| Источник | Почему нельзя |
|---|---|
| CC-BY-NC (некоммерческие) | игра продаётся — это коммерция |
| CC-BY-ND (без производных) | ассеты всё равно меняются (сжатие, ретопология, перекраска) |
| CC-BY-SA для ассетов | может требовать распространения производных на тех же условиях — избегать |
| «Free for personal use», «editorial use only» | запрещено коммерческое использование |
| Ассеты, вытащенные из чужих игр, «рипы», моды | чужая собственность |
| Музыка с YouTube, из TikTok, песни артистов | авторские права |
| Фото из поиска картинок без лицензии | авторские права |
| Шрифты из системы Windows и «скачанные с сайта шрифтов» без лицензии | многие запрещают встраивание в игры |
| Платные паки и подписки | по правилу проекта — только бесплатное |
| Нейросети, условия которых бесплатного тарифа запрещают коммерческое использование | нет прав на результат |
| Клонирование голоса или лица реального человека | права личности; запрещено без письменного согласия |
| 3D-тайлы картографических сервисов, Street View | условия сервисов |
| GPL-код внутри игры | требует открыть код игры; GPL-программы можно использовать только как инструменты |
| Ассеты без понятной лицензии или автора | риск — удаляется |

### 2.5. Хранение проекта бесплатно

- Бесплатные квоты Git LFS у хостингов маленькие (порядка единиц гигабайт хранения и трафика) — для игры на десятки гигабайт этого мало.
- Поэтому: **в Git** — код, данные (JSON, Lua), сцены, конфиги, мелкие ассеты; **крупные исходники** (assets_src: модели, текстуры, звук) — в отдельной папке вне Git с манифестом (список файлов + хэш + лицензия + ссылка на источник), из которого их можно заново скачать.
- Бэкапы: автоматическая копия проекта на внешний диск раз в день (скрипт), раз в неделю — вторая копия в другое место. Сборки (assets_bin) не бэкапятся — они пересобираются.
- Скрипт **han_fetch** по манифесту заново скачивает все бесплатные ассеты из их источников (если ссылка умерла — сообщает, и ассет заменяется).


### 2.6. Процесс проверки каждого ассета

1. Найти ассет только в бесплатном источнике из разрешённого списка.
2. Открыть страницу лицензии; если лицензии нет или она неясна — пропустить.
3. Записать в CREDITS.md: название, автор, ссылка, лицензия, дата, скриншот страницы лицензии (в licenses/proof/).
4. Проверить ассет на чужие товарные знаки (логотипы на одежде, машинах, вывесках) — удалить или заменить своими.
5. После импорта cooker проверяет, что запись в CREDITS.md есть; иначе сборка падает.
6. Перед релизом — финальный аудит: han_licenses строит отчёт по всем ассетам и окно «Лицензии» в игре.


### 2.7. Красные флаги — сразу отказ

- Ассет «слишком хорош для бесплатного» и выложен не автором (перезалив чужого платного).
- На модели машины — настоящая решётка радиатора и узнаваемые формы конкретной модели бренда.
- На одежде — узнаваемые логотипы или паттерны известных брендов.
- Музыка «без авторских прав» без указания автора и лицензии.
- Голос, похожий на известного актёра или стримера.
