## Часть 34. Графика: свет, погода, материалы, текстуры, эффекты

> Цель — картинка, от которой хочется просто стоять и смотреть, на RTX 2050. Секрет — не в тяжёлых технологиях, а в свете, цвете, мокрых поверхностях, неоне и деталях. Все параметры ниже — стартовые, хранятся в data/render/*.json и правятся в редакторе с живым предпросмотром.


### 34.1. Освещение по времени суток

| Время | Солнце, ° | Цвет света | Экспозиция | Небо и туман | Город |
|---|---|---|---|---|---|
| 05:30 | −4 (рассвет) | 2500 K | низкая | сине-розовый градиент, туман над рекой 0,6 | фонари гаснут, первые окна |
| 07:00 | 8 | 3500 K | средняя | мягкий голубой, дымка | утренний поток, холодный свет |
| 10:00 | 35 | 5200 K | дневная | чистое небо, лёгкие облака | резкие тени, стекло бликует |
| 13:00 | 60 | 5800 K | дневная | яркое небо | короткие тени, жарко летом (марево) |
| 17:00 | 25 | 4300 K | дневная | тёплое | длинные тени, золото на стёклах |
| 18:40 | 3 (закат) | 2800 K | переход | оранжево-розовое, облака подсвечены | вывески загораются волной |
| 19:30 | −6 (сумерки) | синий час | вечерняя | глубокий синий, светлый горизонт | неон + синие сумерки — главный «вайб»-кадр |
| 23:00 | луна | 4100 K лунный | ночная | тёмно-синее, смог подсвечен городом снизу | неон, витрины, фары, окна |
| 03:00 | луна | 4100 K | ночная | самое тёмное, туман у реки | окна гаснут, светятся только 24/7 и клубы |

- Время восхода и заката смещается по сезонам (лето — светло дольше).
- Экспозиция — автоматическая с ограничениями (диапазон по времени суток), без «прыжков» при входе в тоннель — адаптация 1,5 с.
- Небо — аналитическая модель атмосферы + слой облаков (2D-текстуры с параллаксом) + звёзды почти не видны (городская засветка), луна с фазами.
- **Город ночью светится сам**: засветка неба снизу оранжево-фиолетовым, окна жилых башен включаются по расписанию (вечером 70%, в 2 часа ночи 10%), рекламные экраны мерцают.


### 34.2. Источники света

| Тип | Цвет | Реализация |
|---|---|---|
| Натриевые фонари (старые районы) | 2000 K | реальный источник только у ближайших 32; дальше — светящаяся текстура + пятно-декаль |
| LED-фонари (новые районы) | 4000 K | то же |
| Неон вывесок | розовый, бирюзовый, красный, янтарный, зелёный | emissive + bloom; 8–16 ближайших дают реальный свет на мокрый асфальт |
| Витрины и 24/7 | 5000 K | прямоугольные area-light-приближения, свет на тротуар |
| Фары машин | 5500 K (LED) / 3200 K (старые) | прожекторы с тенью только у машины игрока и 2 ближайших |
| Экраны телефонов прохожих | холодный голубой | маленький свет на лицо, только рядом с камерой |
| Красные кресты церквей | красный | emissive, видны издалека — силуэт ночного Сеула |
| Огонь, искры | тёплый | мерцающий точечный свет, короткоживущий |

Бюджет: до 256 источников в кадре в clustered-сетке, до 4 источников с тенями; остальное — emissive и bloom.


### 34.3. Погода

| Состояние | Визуально | Механика | Звук и люди |
|---|---|---|---|
| Ясно | резкие тени, яркое небо | — | много людей, уличные музыканты |
| Облачно | мягкие тени, серо-голубое небо | — | обычно |
| Пасмурно | почти нет теней, низкий контраст | — | людей меньше |
| Мелкий дождь | мокрый асфальт, лужи 30%, капли на камере (опция) | сцепление шин −15% | прозрачные зонты, шорох дождя |
| Ливень (чанма) | лужи 80%, ручьи у бордюров, видимость 300 м | сцепление −35%, аквапланирование | улицы пустеют, гром |
| Гроза | ливень + молнии (вспышка неба + свет) | как ливень | гром с задержкой по расстоянию |
| Туман | видимость 150 м, ореолы фонарей | — | приглушённый город |
| Мелкая пыль (смог) | желтоватая дымка, солнце-диск | −5% восстановления стамины на улице | люди в масках |

- Переходы между состояниями — 3–10 игровых минут плавно (мокрость нарастает и высыхает постепенно).
- Вероятности по сезонам: чанма — июль, снег — декабрь–февраль, мелкая пыль — весна.
- Миссии могут фиксировать погоду (ливень в «После пожара», снег в «Пхочжанмача»).


### 34.4. Цепочка пост-обработки (по порядку)

| Проход | Параметры по умолчанию |
|---|---|
| TAA | джиттер 8 фаз, накопление 0,9, защита от «шлейфов» по скорости |
| Глубина резкости | только катсцены, фото-режим, меню (полуразрешение) |
| Размытие в движении | по объектам и камере, 8 сэмплов, выкл. по умолчанию в бою |
| Bloom | 6 уровней мипов, порог 1,0, интенсивность 0,08 (ночью 0,12), лёгкая анаморфная растяжка фар в дождь |
| Блики линз | мягкие, только от солнца и фар, опционально |
| Тонмаппинг | AgX (или ACES) с ручной кривой контраста |
| Цветокоррекция | 3D-LUT 32³ — по району, времени и погоде, смешивание до 3 LUT |
| Виньетка | 0,2; в «плывущем» состоянии бойца — 0,5 с пульсацией |
| Хроматическая аберрация | только на сильных ударах, 2 кадра |
| Зерно | 0,03, опционально; во флешбэке «1988» — 0,15 + сепия + царапины |
| Резкость (FSR / CAS) | 0,3 при апскейлинге |
| Капли на экране | в дождь при камере, смотрящей вверх, опционально |


### 34.5. Отражения и непрямой свет

- Статическое: световые зонды по сетке (запекаются для каждого времени суток — 6 наборов и смешиваются) + запечённая окклюзия в вершинах зданий.
- Отражения: пробы-кубмапы в ключевых местах (обновляются при смене погоды и времени), SSR на «Высоко» для мокрого асфальта и стекла; на «Средне» — SSR половинного разрешения только для мокрых поверхностей.
- SSAO / GTAO полуразрешения. Тени: 3 каскада (ближний 15 м, средний 50 м, дальний 150 м), кэш статики.

### 34.7. Правила текстур

| Тип карты | Формат и правила |
|---|---|
| Цвет | BC7 sRGB (BC1 для простых пропсов); мипы обязательны |
| Нормали | BC5 (две компоненты, Z восстанавливается) |
| ORM и маски | BC7 или BC4 для одноканальных масок |
| Emissive | BC7, HDR-множитель в материале |
| UI | без сжатия или BC7; шрифты — MSDF-атласы |
| Трим-шиты | один атлас 2K на тип здания для карнизов, рам, решёток |
| Детальные текстуры | 512 тайлов поверх крупных поверхностей вблизи (камень, бетон, ткань) |
| Стриминг | дальние мипы постоянно в памяти (до 128 px), старшие подгружаются по дистанции и бюджету |


### 34.8. Декали

Трещины асфальта, заплаты, люки, масляные пятна, следы шин, лужи, граффити (200 вариантов, часть — коллекционные), стикеры и листовки на столбах, подтёки на бетоне, мусор, жвачка, следы ног в снегу, кровь (капли, брызги, мазки, лужи), пот на татами, трещины стекла, вмятины на машинах (декаль + деформация), опавшие листья и лепестки, пятна масла в мастерских, разметка парковок, номера корпусов домов.


### 34.9. Вывески и тексты города

- Тысячи вывесок генерируются из словаря вымышленных названий по типу заведения и улицы (курица, кафе, пиджи-бан, стоматология, академия-хагвон, церковь, недвижимость…), шрифтами с хангылем.
- Текст рендерится в атлас вывесок при загрузке ячейки (MSDF-шрифты — чётко на любом расстоянии), к нему добавляются рамка, подсветка, неон или LED по стилю.
- Ручные вывески у геройских кварталов — уникальные, с юмором и пасхалками.

### 34.11. Персонажи и машины: рендер

- Кожа: предынтегрированное подповерхностное рассеяние, микро-нормаль пор, маски пота (растёт в бою), мокрой кожи (дождь), синяков, тату (запекаются в слой).
- Волосы: карточки, анизотропный блик, сортировка, мокрые волосы темнее и блестят.
- Глаза: отдельная роговица, блик, влажность.
- Одежда: блеск ткани, намокание по маске, грязь после падений.
- Машины: двухслойная краска (база + лак), металлик-хлопья, грязь по сезону, капли дождя, отражения проб, повреждения — смешение с текстурой царапин по маске урона.
