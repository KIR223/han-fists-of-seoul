## Часть 70. Чего не делать

- Не делать мультиплеер.
- Не делать универсальный редактор уровня Unreal — только инструменты для этой игры.
- Не писать свою базовую физику, звуковой движок и UI-движок, если готовые библиотеки справляются.
- Не использовать реальные бренды, логотипы, марки машин, реальные имена людей, музыку без лицензии.
- Не копировать дословно чужие игры (тексты, интерфейс, анимации) — только ориентиры по ощущениям.
- Не делать новые районы, пока вертикальный срез не отполирован.
- Не превращать игру в шутер.
- Не делать бесплатные открытия приёмов — всё изучается.
