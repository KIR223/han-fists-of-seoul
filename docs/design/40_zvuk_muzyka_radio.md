## Часть 40. Звук, музыка, радио


### 40.1. Звук

- Удары по зонам и силе, свист ударов, шлепки по коже, глухие удары тела о мат, асфальт, стекло; дыхание и выкрики бойцов по стилю.
- Эмбиент по районам и времени суток, реверберация по зонам (переулки, тоннели, залы, метро, подземные галереи).
- Звук из физики (см. «Физика»), 3D-позиционирование, затухание.
- Микшер: Master / Music / SFX / Voice / Ambient / UI.


### 40.2. Музыка

- Динамическая боевая музыка: нарастает в больших драках, особые темы для дуэлей мастеров и финальных боёв.
- Музыка залов (у каждого свой жанр), клубов, магазинов, пиджи-банов.
- Вся музыка — только CC0, CC-BY или своя; без настоящих песен K-pop и любых исполнителей.
