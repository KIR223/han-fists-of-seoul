## Часть 65. Ассеты: источники и учёт лицензий

Владелец не рисует и не моделирует. Выбери **единый визуальный стиль** (рекомендация — стилизованный полуреализм, см. «Атмосфера и вайб»), под который реально найти ассеты. На первом этапе предложи владельцу 2 варианта с примерами бесплатных ассетов.

| Что нужно | Где искать (проверять лицензию каждого ассета!) |
|---|---|
| Персонажи и риг | Mixamo (бесплатно, коммерческое использование разрешено, исходники не распространять), Quaternius (CC0), Sketchfab — только CC0 / CC-BY, MakeHuman (выходные модели — CC0) |
| Азиатские лица и одежда | MakeHuman (CC0-выход) и бесплатные CC0 / CC-BY модели; разнообразие лиц через блендшейпы и смешивание |
| Анимации | см. «Анимация высокого уровня» |
| Город | модульные киты зданий, Sketchfab (корейские здания, ханоки, магазины, вывески), Quaternius, Kenney (CC0) + генерация из OSM |
| Машины | Sketchfab, Quaternius (без логотипов реальных брендов — логотипы заменяем своими текстурами) |
| Текстуры и небо | Poly Haven, ambientCG (CC0) |
| Тату-эскизы | PNG со свободной лицензией (OpenGameArt, CC0-коллекции) |
| UI-иконки | Kenney UI, Game-icons.net (CC-BY), Material Symbols |
| Шрифты | Google Fonts: Noto Sans, Noto Sans KR |
| Звуки | Freesound — только CC0 и CC-BY, Kenney audio (CC0), бесплатные архивы Sonniss GDC (проверить условия), свои записи |
| Музыка | CC0-музыка (например, FreePD), OpenGameArt (CC0 / CC-BY), Incompetech (CC-BY); своя музыка в LMMS из CC0-сэмплов |
| Карта | OpenStreetMap (ODbL), SRTM (рельеф), Copernicus DEM GLO-30 (свободная с указанием авторства) |

- **Только бесплатное** (см. «Главное правило: всё бесплатно и юридически чисто»). Ассеты магазинов других движков не используются вообще.
- **ASSETS_TODO.md**: что нужно, зачем, где искать, куда положить (assets_src/...), как назвать, приоритет.
- **CREDITS.md**: ассет, автор, ссылка, лицензия, требуется ли указание авторства. CC-BY и ODbL — в титрах.
- **Конвейер полностью автоматический**: владелец кладёт скачанный файл в папку — он становится игровым.
- Нет подходящей анимации или модели — ближайшая замена с пометкой «заменить позже».
- Искать ассеты в интернете и переделывать их под игру — можно и нужно, но только со свободной лицензией: правила, источники и конвейер — в части «Ассеты из интернета: найти, проверить, переделать».
