## Часть 17. Управление: легко освоить, глубоко мастерить

> Управление должно быть **лёгким**. По умолчанию включена **простая схема**: весь бой — две кнопки мыши и три клавиши, как в Sleeping Dogs и серии Batman Arkham. Глубина — в ритме нажатий, выборе момента и стилях, а не в количестве клавиш. Для желающих есть схема **«Мастер»** с полным ручным контролем.


### 17.1. Принципы лёгкого управления

- **Минимум клавиш.** Новичку в бою нужны только ЛКМ, ПКМ, Space, E и R. Всё остальное — по желанию.
- **Всё контекстное.** Одна клавиша действия F: войти, сесть, купить, поговорить, поднять предмет, добить у стены.
- **Никаких одновременных нажатий трёх клавиш.** Максимум — направление + одна кнопка.
- **Удержание вместо комбинаций.** Сильный удар — удержать ЛКМ; блок — удержать ПКМ.
- **Умная игра за игрока.** Автонаведение на ближайшего врага, автоматический выбор высоты удара, автоматическое чередование рук и ног по стилю, автопаркур при спринте на препятствие.
- **Подсказки, когда нужно.** Над врагом вспыхивает значок контратаки, у стены — значок добивания; в первые часы игры показываются подсказки клавиш, потом исчезают сами.
- **Новое — по одному.** Каждая механика вводится отдельно в безопасной ситуации (см. «Обучение управлению»).
- **Одинаковая логика везде.** ЛКМ всегда «действовать / бить», ПКМ — «защищаться / контра», Space — «уйти», E — «схватить», F — «взаимодействовать», R — «особое».


### 17.2. Простая схема (по умолчанию)


#### Вне боя

| Клавиша | Действие |
|---|---|
| W A S D | движение |
| Мышь | камера |
| Shift | бег (удерживать; можно сделать переключателем); на препятствии — автоматический паркур |
| Space | прыжок |
| Ctrl | присесть / скрытность |
| F | всё взаимодействие: двери, машины, магазины, разговоры, поднять предмет, сесть на лавку |
| T | телефон |
| M | карта |
| Tab (удерживать) | колесо: стили, эмоции, радио, предметы — с замедлением времени |
| Esc | пауза |
| J / K / L | журнал / навыки / стили (по желанию — всё есть и в меню паузы) |
| F1 | справка по управлению в любой момент |


#### В бою

| Ввод | Действие |
|---|---|
| ЛКМ (нажимать) | удары. Ритм нажатий строит комбо: стиль сам чередует руки и ноги, выбирает высоту |
| ЛКМ (удерживать) | сильный удар; в конце серии — финишер стиля |
| ПКМ (нажать, когда враг вспыхнул) | **контратака** — главный приём защиты; у каждого стиля своя |
| ПКМ (удерживать) | блок |
| Space | уклон от удара в сторону движения; без направления — отскок назад |
| E | захват: дальше ЛКМ — бить, E + направление — бросок, F — к стене или объекту, Space — отпустить |
| R | спецприём стиля (тратит Фокус) |
| F | добивание у окружения, поднять предмет |
| Колесо мыши или 1–4 | сменить стиль |
| W A S D + ЛКМ (по желанию) | направление меняет ветку комбо: к врагу — прямые, в сторону — боковые, от врага — удар с отходом |


#### Ритм комбо в простой схеме

Обозначения: **●** — нажатие ЛКМ, **■** — удержание ЛКМ, **…** — короткая пауза (около 0,4 с).

| Ритм | Что получается (пример для бокса / тхэквондо) |
|---|---|
| ● ● ● ● | базовая серия: джеб, кросс, хук, апперкот / бандаль, бандаль, доллё-чаги, твит-чаги |
| ● ● ■ | серия с силовым финишером: двойка и оверхенд / два удара и удар с разворота |
| ● … ● ● | вторая ветка: джеб, пауза, удар по корпусу и хук в голову / финт и двойной в прыжке |
| ● ● … ■ | третья ветка: сильный финишер стиля (у тайского бокса — колено в прыжке) |
| ■ | одиночный силовой удар — пробивает блок |
| ПКМ → ● ● | контратака и продолжение серией |
| Space → ● | удар из уклона |
| E → ● ● ● → E | захват, удары (у тайского бокса — колени), бросок |

У каждого стиля 4–6 ритмических веток. Новые ветки открываются с мастерством. Список веток всегда виден в Комбо-книге и, по желанию, маленькой подсказкой на экране.


#### Умный выбор (только простая схема)

- Если враг держит высокий блок — следующий удар идёт в корпус; если отступает — лоу-кик или рывок; если наклонился — апперкот или колено; если лежит — удар сверху.
- Если стиль не борцовский, E делает простой захват и толчок; у борцовских стилей E на дистанции — проход в ноги.
- В партере: ЛКМ — удары сверху, E — лучший доступный переход, R — сабмишен, Space — встать. Сабмишен: «нажимай ЛКМ в ритм пульса» (вариант попроще) или «держи метку мышью в зоне» (вариант посложнее).


### 17.3. Классическая схема (середина)

Для тех, кому простой мало, а «Мастер» — много: руки на ЛКМ, ноги на ПКМ, блок на Q (удержание), парирование — Q вовремя, контратака — ПКМ при вспышке врага, высота удара выбирается автоматически, захват E, уклон Space, спецприём R.


### 17.4. Переключение схем

- Схему можно сменить **в любой момент**: в настройках или прямо в меню паузы, без потери прогресса и навыков.
- Режим **«Своя»** — выбрать сложность отдельно для боя, клинча и партера, машины, мини-игр и паркура (см. «Настройки: полный список»).
- Комбо-книга и подсказки автоматически показывают ввод для текущей схемы.


### 17.5. Схема «Мастер» (по выбору)

Полный ручной контроль для тех, кто хочет глубины. Включается в настройках или при новой игре; можно переключаться в любой момент. **Ввод приёмов в таблицах стилей указан для этой схемы.**

| Ввод | Действие |
|---|---|
| ЛКМ / ЛКМ (удерж.) | удар рукой / силовой удар рукой |
| ПКМ / ПКМ (удерж.) | удар ногой или коленом / силовой удар ногой |
| W A S D + удар | ↑ к противнику — прямой; ← / → — боковой; ↓ от противника — снизу или с отходом |
| Колесо мыши | уровень атаки: голова ↔ корпус ↔ ноги; нажатие колеса — захват цели |
| Space + направление | уклон, шаг, отскок; двойное — перекат |
| C | нырок под удар |
| Q (удерж.) / Q вовремя | блок / парирование |
| Q + S | чек коленом против лоу-кика |
| E / E + S / E вовремя | захват, клинч / проход в ноги / поймать ногу |
| Shift | рывок на сближение |
| Z | сменить стойку |
| R / R + направление | спецприёмы |
| 1–4 | стили |
| F | окружение |
| X | провокация |

Нотация в таблицах приёмов: **Л** — ЛКМ, **П** — ПКМ, **Л+** / **П+** — удержание, **↑ ↓ ← →** — W / S / A / D относительно противника, **→** между нажатиями — следующее нажатие, **C**, **E**, **R**, **Q**, **Space** — клавиши.


### 17.6. Помощники (включаются и выключаются в настройках)

| Помощник | Что делает |
|---|---|
| Автонаведение | удары доворачивают к ближайшему врагу перед камерой |
| Автовысота | игра сама выбирает голову, корпус или ноги (только простая схема) |
| Подсказка контратаки | значок над врагом перед ударом, который можно контратаковать |
| Замедление контратаки | на «Лёгкой» время чуть замедляется перед контратакой |
| Автоблок | на «Лёгкой» блок срабатывает сам при бездействии |
| Автопаркур | перелезание и подъём при беге на препятствие без нажатия Space |
| Бег-переключатель | Shift один раз — бежать, ещё раз — идти |
| Помощник руля | машину не заносит на клавиатуре, плавный руль |
| Упрощённые мини-игры | больше окна, медленнее метки, автоматический ритм |
| Подсказки комбо | мини-список ритмов текущего стиля в углу экрана |


### 17.7. Обучение управлению

1. Первые 15 минут: только ходьба, бег, F и камера (вводная миссия).
2. Первая драка: только ЛКМ и Space. Контратака (ПКМ) — во второй волне, со значком и замедлением.
3. Захват (E) и добивание у стены (F) — в миссии «Первая победа».
4. Спецприём (R) и смена стилей — когда изучен второй стиль.
5. Каждая новая механика — короткая подсказка из 1–2 строк и безопасная ситуация, где её нельзя провалить.
6. **Полигон** в зале открыт всегда: манекены, спарринг-партнёры, отображение ввода и ритма на экране.
7. Справка F1 и раздел «Обучение» в журнале — пересмотреть любую подсказку.


### 17.8. Машина и транспорт

| Клавиша | Действие |
|---|---|
| W / S | газ / тормоз и задний ход (плавное нарастание) |
| A / D | руль |
| Space | ручник |
| Мышь | свободный обзор, камера сама возвращается за машину |
| F | выйти; на ходу с мотоцикла — спрыгнуть |
| Tab | колесо радиостанций |
| Q | гудок |
| C | смена камеры |
| V (удерж.) | кинокамера |
| Shift | нитро (если установлено) |

Фары, дворники и поворотники включаются автоматически; при желании — ручное управление в настройках.


### 17.9. Геймпад (вторично)

Квадрат / X — удары, Треугольник / Y — контратака, Круг / B — захват, Крест / A — уклон, R1 / RB — спецприём, L1 / LB — блок, крестовина — стили, R3 — захват цели. Иконки подсказок меняются автоматически.
