## Часть 12. Просто жить в Сеуле: вайб, культура, спокойные занятия

> Игрок должен хотеть играть, даже когда не хочет драться: гулять, ездить, есть, смотреть на реку, слушать радио. Эти занятия — полноценная часть игры, а не «мини-игры для галочки».


### 12.1. Режим прогулки

- Включается в настройках или на телефоне («Не беспокоить»): нет случайных драк, банды не нападают, полиция не реагирует на мелочи, друзья звонят только по делу. Сюжетные миссии просто не стартуют.
- Включается автоматически предложением после тяжёлых сюжетных глав («Хочешь просто погулять?»).
- Ничего не блокирует: можно в любой момент выключить и вернуться к игре.


### 12.2. Спокойные занятия

| Занятие | Как это работает |
|---|---|
| Ночные поездки | кинокамера, радио, тихий режим; «круиз-маршруты» на карте: набережные, мосты, Намсан, Каннам-дэро |
| Прогулки | медленный шаг (короткие нажатия W), камера ниже и ближе, персонаж смотрит по сторонам, музыка тише |
| Посидеть | лавки, ступени, края крыш, набережные: камера отъезжает, время можно ускорить, восстанавливается Фокус |
| Рамён у реки | автомат варки рамёна в магазине у Хангана, складной стол, вид на мост — сохранение и бафф |
| Кафе | заказать кофе (меню с фото), сесть у окна, смотреть на улицу, слушать разговоры за соседними столами |
| Кот-кафе | гладить котов (мини-сценка), кот садится на колени — достижение |
| Книжный магазин | читать вымышленные манхвы и журналы о боях (короткие тексты, бонус к Наблюдательности) |
| Фото | фото-режим, фото-маршруты фотографа-ветерана, «тогда и сейчас», фото попадают в соцсеть игры |
| Норэбан с друзьями | ритм-караоке, бубны, друзья поют фальшиво (смешно) |
| Пикник у реки | заказать курицу с доставкой прямо к реке, курьер находит тебя на набережной |
| Велосипед по набережной | прокат велосипеда, длинные дорожки вдоль реки на закате |
| Походы в горы | тропы Инвансана и Намсана, аджуммы в походной одежде, панорамы, фото |
| Темпл-стей | ночь в храме: утренняя церемония, медитация, монастырская еда |
| Чимчильбан | бани, сауна, яйца и сикхе, сон на полу среди людей (сохранение) |
| Ночной рынок | уличная еда, тир с пневматикой, лотереи, примерка одежды |
| Дом | готовка, уход за котом на крыше, полив растений, телевизор с вымышленными шоу, гитара (мини-игра) |
| Метро ради метро | ехать по кольцевой линии 2 и смотреть на город из окна на мостах |
| Смотреть на город | смотровые площадки: Намсан, мосты, крыши — короткая музыкальная тема при первом визите |


### 12.3. Корея в деталях

| Тема | Как отражено в игре |
|---|---|
| Вежливость и иерархия | поклоны старшим, обращения в субтитрах (хён, нуна, сонбэ, аджосси, сонсэнним), старшие наливают — младший держит рюмку двумя руками; NPC реагируют, если герой груб со старшими |
| Еда | застолья, курица с пивом, барбекю (жарить мясо — мини-игра), банчханы, доставка куда угодно, еда в одиночку |
| Ночная жизнь | 2–3 «круга» застолья, норэбан после, пьяные офисные компании, ожидание такси в 2 ночи |
| Работа | переработки, хведжик (обязательный ужин с коллегами), офисные работники засыпают в метро |
| Учёба | районы с хагвонами (частными школами), студенты в кафе до утра, госэкзамены соседа по госивону |
| Жильё | госивоны, комнаты на крыше, подвальные квартиры, жилые комплексы с номерами корпусов |
| Доставка | курьеры повсюду, еда приезжает куда угодно — даже в парк |
| Чистота и порядок | урны раздельного сбора, люди ждут зелёного, очередь в метро по разметке |
| Технологии | все в телефонах, оплата телефоном, умные остановки, Wi-Fi в метро |
| Религия и город | красные неоновые кресты на крышах, буддийские храмы в горах, фонари на праздник Будды |
| Спорт и культура | бейсбол (стадион Чамсиль), уличные танцоры, айдол-стажёры, фан-культура |
| Сезонные ритуалы | сакура, чанма, летние пикники, осенние клёны, зимний хотток, первый снег — особое событие |
| Праздники | Соллаль (город пустеет), Чхусок, день рождения Будды (фонари), Рождество в Мёндоне, фейерверки на Ёыйдо |


### 12.4. Календарь года

| Месяц | Что в городе |
|---|---|
| Январь–февраль | снег, холод, Соллаль (пустые улицы, семьи в ханбоках, закрытые магазины), зимние турниры |
| Март–апрель | сакура на Ёыйдо и у реки, жёлтая пыль, маски, весенние фестивали университетов |
| Май | фонари к дню рождения Будды у храмов и Чхонгечхона, тепло, пикники |
| Июнь–июль | жара, цикады, сезон чанма — ливни, ручьи на улицах |
| Август | душные ночи, люди ночуют в палатках у реки, ночные рынки |
| Сентябрь–октябрь | Чхусок, фестиваль фейерверков на Ёыйдо, клёны на Намсане и у дворцов |
| Ноябрь | первый снег — особое событие, хотток, туманы |
| Декабрь | Рождество в Мёндоне, иллюминация, турнир «Король Сеула» по сюжету (если доступно) |

Игровой год длится 30–40 часов игры (сезон ≈ 8–10 часов); его можно зафиксировать в настройках.


### 12.5. Город говорит

- Сотни коротких диалогов прохожих по ситуациям: о работе, погоде, ценах на квартиры, сериалах, бейсболе, о самом Тэхо (после вирусных роликов).
- Радио, ТВ, соцсеть и новости реагируют на сюжет и поступки игрока: «Курьер-боец из Мокпхо снова в топе», «Рынок Мангвон: торговцы против сноса».
- Вымышленные ТВ-шоу: кулинарное, дорама (смешные отрывки), шоу выживания айдолов, новости, реклама.
- Интернет в телефоне: форум бойцов с обсуждениями рейтинга, сайты кафе, объявления о комнатах.


### 12.6. Питомец

- На крыше появляется уличный кот (после побочной истории «Кошачья мама»): имя выбирает игрок, кот спит на кровати, встречает героя, иногда приносит «подарки». Кормить — по желанию, без наказаний.
