## Часть 67. Производительность: сводка

| Параметр | Бюджет |
|---|---|
| Цель | 1080p, стабильные 60 FPS на «Средне» (FSR «Качество» допустимо); 30+ FPS на «Высоко» |
| Время кадра CPU | до 12 мс в самом нагруженном месте (толпа + трафик + бой 1 на 8) |
| Время кадра GPU | до 14 мс на «Средне» |
| Физика | 3–5 мс CPU и до 1,5 мс GPU |
| VRAM | не больше 3,2 ГБ на «Средне» |
| ОЗУ игры | не больше 6 ГБ |
| Треугольники в кадре | до 3 млн после отсечения |
| Персонажи | игрок до 40 тыс. треугольников, NPC до 15 тыс. с 3 LOD; до 80 анимированных рядом |
| Машины | до 30 с физикой рядом |
| Текстуры | в основном 1K–2K, BC7 / BC5 / BC1, стриминг мипов |
| Загрузка | первый вход до 20 с на SSD; дальше без экранов загрузки |

- Пресеты Низко / Средне / Высоко / Своё + «Качество физики»; автоопределение при первом запуске.
- Оверлей производительности (F3) и Tracy в разработческой сборке.
- Фича, проваливающая бюджет на бенчмарк-маршруте, не считается готовой.
