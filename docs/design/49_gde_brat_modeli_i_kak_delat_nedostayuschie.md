## Часть 49. Где брать модели и как делать недостающие


### 49.1. Порядок поиска ассета

1. **CC0-библиотеки** (Poly Haven, ambientCG, Quaternius, Kenney, CC0 на Sketchfab) — без ограничений.
2. **Бесплатные с указанием авторства** (CC-BY) — записать в CREDITS.md.
3. **Кит-бэш**: собрать нужное из частей уже имеющихся ассетов (лоток рынка = стол + навес + ящики).
4. **Сделать самим** (Claude, программно) — если нигде нет или стиль не подходит (см. ниже).
5. **Генерация нейросетью** (изображение или текст → 3D) — только если условия сервиса разрешают коммерческое использование, с обязательной чисткой сетки и текстур и одобрением владельца.
6. **Упростить**: если ничего не подходит — изменить задумку так, чтобы хватило бесплатного (например, другой ракурс, силуэт, ночная сцена).


### 49.2. Как Claude делает модели сам

- **Blender в фоновом режиме + Python (bpy)**: Claude пишет скрипты, которые строят модели процедурно — вывески, лотки, палатки пхочжанмача, урны, столбы, ограждения, модули фасадов, элементы ханоков (балки, черепица, ворота), лестницы, крыши с баками, мебель, ящики, рамы окон. Владелец ничего не делает руками.
- **Geometry Nodes** (через скрипты) — для вариаций: десятки вывесок, стеллажей, заборов из одного генератора.
- **Процедурные материалы**: шейдерные графы Blender запекаются в текстуры (цвет, нормаль, ORM) — бетон, краска, ржавчина, плитка, дерево; или Material Maker (MIT) из командной строки.
- **Правила красоты для своих моделей**: фаски на рёбрах (никаких идеально острых углов), трим-шиты для деталей, маски износа (грязь в углах, потёртости на краях), реальные пропорции по фото-референсам, единая плотность текселей, LOD и коллизии генерируются тем же скриптом.
- **Проверка**: Claude рендерит модель в движке рядом со скачанными ассетами при трёх освещениях (день, ночь, дождь), сам смотрит скриншоты и сравнивает с референсом; владелец утверждает или просит поправить.
- **Чего Claude не делает сам**: лица и тела людей, сложные органические формы, анимации тела — только скачанные бесплатные.

Подробно о поиске в интернете, допустимых лицензиях и конвейере переделки — в части «Ассеты из интернета: найти, проверить, переделать».


### 49.3. Справочные фото

- Для точности Claude собирает список референсов (описания мест и ссылок на свободные фото: Wikimedia Commons, Unsplash и т. п. — только как референс, не как текстуры, если лицензия не разрешает).
- Для каждого геройского квартала — лист референсов: вывески, цвета, материалы, мебель улиц, характерные детали.
