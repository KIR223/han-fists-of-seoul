## Часть 43. Катсцены

> Катсцены — сердце подачи сюжета. Они снимаются как кино: продуманные планы, свет, паузы, музыка. Все — в движке, в реальном времени, с текущей одеждой, синяками и телом героя, без загрузок на входе и выходе.


### 43.1. Виды сцен

| Вид | Длительность | Где используется |
|---|---|---|
| Кинематографическая катсцена | 1–3 мин | повороты сюжета, начало и конец глав |
| Диалог в движке | 0,5–2 мин | разговоры с мастерами, друзьями, торговцами: камера «восьмёркой», игрок может выбирать ответы |
| Разговор на ходу | любая | поездки и прогулки с друзьями — реплики во время игры, как в GTA V |
| Телефонный звонок | 0,2–1 мин | окно с лицом звонящего, игра продолжается |
| Панели манхвы | 5–15 с | появление сильного бойца, вызов, смешные моменты: стоп-кадр в рамке с именем |
| Флешбэк | 1–5 мин | 1988 и 2008 годы: чёрно-белое или выцветшее изображение, зерно, звук как с плёнки |
| Монтаж | 1–2 мин | тренировки, восстановление зала: короткие планы под музыку |
| Финиш-камера боя | 2–4 с | нокаут: замедление, облёт камерой, вспышка |


### 43.2. Правила постановки

- **Язык камеры**: общий план — где мы; средний — кто; крупный — что чувствует. Не держать один план дольше 8 секунд без причины. Правило 180 градусов в диалогах.
- **Объектив**: 24–35 мм для общих планов города, 50 мм для разговоров, 85 мм для крупных лиц; глубина резкости — только на крупных и средних.
- **Свет**: в каждой сцене — ключевой источник, оправданный миром (вывеска, окно, фонарь, экран телефона). Для лиц в катсценах — дополнительный мягкий заполняющий свет, невидимый в игре.
- **Тишина**: важные эмоции — без музыки, только город. Музыка входит после реплики, а не поверх.
- **Ритм**: смешные сцены — быстрые склейки; тяжёлые — длинные планы, пауза перед ответом.
- **Переходы**: из геймплея в сцену — камера плавно отъезжает от точки обзора игрока; из сцены в геймплей — последний план совпадает с игровой камерой.
- **Пропуск**: удержание Space; повторный просмотр — в журнале («Галерея сцен»).
- **Субтитры** всегда; имя говорящего цветом персонажа.


### 43.3. Инструменты

- Секвенсор в редакторе: дорожки камер, персонажей (анимации, взгляд, IK рук), лиц (эмоции, губы), звука, света, эффектов, погоды и времени, событий геймплея; предпросмотр в реальном времени.
- Автоматическая синхронизация губ по аудио; ручная правка ключевых эмоций.
- Черновая озвучка синтезом позволяет собирать катсцены сразу, финальная запись подменяется по ключам.
- Камеры с «ручной» тряской (шумовой генератор), рельсы, кран, слежение за костью.
- Каждая сцена — файл .seq; список всех сцен — cutscenes.json с актами, длительностью, статусом (черновик, анимация, звук, готово).
