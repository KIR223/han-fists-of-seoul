## Часть 0. Как пользоваться этим документом (для тебя, не для Claude)

Это полный дизайн-документ и свод правил, по которым Claude Code будет **шаг за шагом** писать собственный игровой движок и игру на нём. Честно о масштабе: свой движок + открытый мир по реальной карте + боёвка уровня лучших файтинг-экшенов — это огромный проект. С Claude Code он реален, но займёт **долго**: месяцы до первой играбельной версии (один район, бой, машины, полиция) и годы до полной. Поэтому план разбит на маленькие этапы, и после каждого есть что запустить.

1. Поставь: Windows 10/11, **Visual Studio 2022** (компонент «Разработка классических приложений на C++»), **CMake**, **Git** и **Git LFS**, **Vulkan SDK** (LunarG), **Blender** (только для автоматической конвертации моделей скриптами — рисовать ничего не нужно), **Claude Code**.
2. Создай пустую папку проекта и положи туда **GAME_DESIGN.md** (тот же текст, что и в этом PDF) и папку **design/** с этим же документом, разбитым по частям (файлы прилагаются).
3. Запусти Claude Code в этой папке и напиши: «Прочитай design/INDEX.md и части 0–2, затем выполни часть «Первое задание»». Документ очень большой, поэтому Claude читает его по частям — нужные для каждого этапа (см. «Технические приложения»).
4. Дальше идите по этапам из части «План разработки». Claude сам компилирует, запускает тесты и делает скриншоты. Твоя задача — запускать сборку, играть, говорить, что не так, и скачивать ассеты по списку ASSETS_TODO.md.
5. Модель: **Opus** — архитектура движка, рендер, физика, анимация, боевая система, сложные баги. **Sonnet** — контент, UI, миссии, мини-игры, правки.
6. Не торопи этапы и не проси «сразу весь город». Сначала один квартал, в котором всё ощущается отлично.
