Около 65 костей. Mixamo-риг и другие гуманоидные риги ретаргетятся на этот скелет автоматически по таблице соответствия имён. Для ragdoll из скелета строится тело из 15–20 капсул.


### 48.4. Блендшейпы

- **Лицо**: стандартный набор из 52 форм (моргание, взгляд, брови, щёки, нос, челюсть, губы, язык) — если скачанная голова его поддерживает; иначе — набор из 20 базовых (эмоции + визем-формы).
- **Синяки и отёки**: маски текстуры (не блендшейпы) — глаз, скула, губа, бровь; плюс 3 блендшейпа отёка.
- **Тело**: мышцы +, жир +, худоба — три формы на базовом теле; одежда получает те же формы автоматически переносом (cooker) — чтобы одежда не проваливалась при изменении тела.

### 48.13. Эффекты (FX)

Удары: пот, брызги, пыль, искры на стальных предметах, вспышка чистого попадания, следы ударов ног (дуга). Окружение: дождь, капли, лужи-круги, брызги из-под колёс, туман, пар (одэн, люки зимой), снег, сакура, листья, мелкая пыль. Транспорт: дым шин, выхлоп, искры, огонь, стекло. Город: фонтан Банпо, фейерверки, неон-мерцание.

### 48.16. Какую модель Claude использовать

| Модель | Для чего |
|---|---|
| Opus | архитектура движка, рендер, физика, анимационная система, боевая система, ИИ, стриминг мира, оптимизация, сложные баги, любые решения, которые потом трудно переделать |
| Sonnet | контент по готовым системам: приёмы в JSON, миссии на Lua, мини-игры, UI-экраны, магазины, диалоги, локализация, мелкие правки |
| Правило | если Sonnet дважды не смог починить одну и ту же проблему — переключиться на Opus |
