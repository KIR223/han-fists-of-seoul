## Часть 47. Настройки: полный список

> Все настройки, которые игрок ждёт от хорошей игры. Каждая применяется сразу (кроме помеченных «перезапуск»), имеет подсказку справа с картинкой «до / после» и оценкой влияния на FPS. Значения по умолчанию — для RTX 2050.


### 47.1. Управление: лёгкое и сложное переключается в любой момент

| Настройка | Значения | Описание |
|---|---|---|
| Схема управления | Простая / Классическая / Мастер / Своя | переключается в настройках и прямо в меню паузы, без потери прогресса |
| Своя: бой | простой / мастер | ритм ЛКМ и автовысота или полный ручной контроль |
| Своя: клинч и партер | простой / мастер | контекстные переходы или ручной выбор направления и давления мышью |
| Своя: машина | с помощником / без | стабилизация, плавный руль |
| Своя: мини-игры | упрощённые / обычные / сложные | окна и скорость меток |
| Своя: паркур | авто / по кнопке | перелезание при беге или только по Space |
| Классическая | — | середина: руки на ЛКМ, ноги на ПКМ, блок Q, но высота удара автоматическая и контратака по ПКМ |
| Подсказка «Попробуй Мастер» | вкл / выкл | предложить сложную схему, когда игрок освоил простую |
