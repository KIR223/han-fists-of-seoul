## Часть 36. Телефон, соцсети, отношения, своя команда


### 36.1. Телефон

| Приложение | Функции |
|---|---|
| Карта | GPS, метки, легенда, фильтры, маршрут, районы и территории банд |
| Звонки и контакты | друзья, мастера, такси, эвакуатор, подмога, трезвый водитель |
| Мессенджер | переписки, приглашения на бои, задания, групповые чаты зала, мемы, спам |
| Стрим | запуск эфира, статистика, донаты, подписчики (см. «Прямой эфир») |
| Видео | записи своих боёв из системы повторов, монтаж, публикация ради славы |
| Соцсеть | лента вымышленных пользователей, реакции на поступки героя, вирусные ролики с ним |
| Журнал бойца | стили, приёмы, звёзды, комбо-книга, Конструктор стиля, статистика боёв |
| Банк и биржа | баланс, переводы, кредит, акции |
| Доставка | заказ еды домой; приём заказов как курьер |
| Авто | покупка машин, вызов своей машины, страховка, штрафы с камер |
| Камера | фото, селфи, режим фото |
| Интернет | вымышленные сайты: новости, форумы бойцов, магазины-пародии, объявления, вики районов |
| Знакомства | приложение свиданий |
| Погода и метро | прогноз, мелкая пыль, схема метро, расписание поездов |
| Настройки | все настройки игры |


### 36.2. Друзья и отношения

- Друзья со шкалой отношений: совместные занятия — пиджи-бан, норэбан, курица с пивом, пхочжанмача, кино, боулинг, бильярд, бейсбольные клетки, ночной рынок, прогулка у реки.
- Бонусы дружбы: скидки, подмога в драке, бесплатный тренер, машина напрокат, информация о боях, ночлег.
- Свидания через приложение и в мире — романтика без откровенных сцен.
- Друзья сами звонят и зовут (частота настраивается); игнорирование снижает отношения.


### 36.3. Своя команда

- До 4 последователей: завербованные бойцы, ученики своего зала, друзья.
- Команды: следовать, ждать, атаковать цель, защищать, разойтись. У каждого свой стиль и уровень, их можно тренировать и экипировать.
