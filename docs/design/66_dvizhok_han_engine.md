## Часть 66. Движок HAN Engine


### 66.1. Философия

- Движок **под эту игру**: открытый мир по реальной карте, толпы, неон, дождь, рукопашный бой, физика. Не универсальный движок «на всё».
- Данные важнее абстракций: плоские массивы, системы, обрабатывающие компоненты пачками.
- Проверенные открытые библиотеки — для того, что не является фишкой (окна, звук, базовая физика); своё — там, где уникальность (боёвка, анимационный граф и motion matching, активный ragdoll, стриминг города, рендер ночи).
- Каждая подсистема тестируется отдельно и имеет отладочную визуализацию.
- Платформа: Windows 10/11 x64, MSVC (сборка также clang-cl). Linux — не приоритет.

### 66.4. Ядро

- Игровой цикл: фиксированный шаг симуляции 60 Гц (физика, бой, ИИ), рендер с интерполяцией на любой частоте.
- **Job system** на всех ядрах: анимация, ИИ, отсечение, стриминг, физика — параллельно.
- Память: фрейм-аллокаторы, пулы, бюджеты подсистем с выводом в оверлей, поиск утечек в отладке.
- **Горячая перезагрузка**: шейдеры, текстуры, JSON приёмов и стилей, Lua-скрипты.
- **Детерминированность** боя при одинаковом вводе — для повторов и автотестов.
- Аварийные дампы с логом. Консоль (~) и cvars: телепорт, деньги, стили, розыск, время, погода, спавн, неуязвимость, замедление, показ хитбоксов, навмеша, коллизий, бюджетов.


### 66.5. Рендер

- Vulkan 1.3: dynamic rendering, synchronization2, bindless-дескрипторы, timeline semaphores.
- **Render graph** с автоматическими барьерами и переиспользованием памяти.
- **Clustered forward+** — сотни неоновых источников ночью; реальные источники ограничены, остальное — emissive + bloom.
- PBR-материалы; шейдеры: статика, скиннинг, кожа (тату, синяки, пот, мокрая кожа), машины (краска, лак, грязь, капли), стекло, вода реки, неон и LED-экраны, листва, мокрый асфальт с лужами.
- **GPU-driven отсечение**: frustum + Hi-Z occlusion на компьют-шейдерах, multi-draw indirect, инстансинг.
- LOD (meshoptimizer), **HLOD** для дальних кварталов, импосторы для силуэта города и гор.
- Каскадные тени с кэшированием статики; тени от фонарей — только у нескольких ближайших.
- Небо: аналитическое, облака, смог по качеству воздуха, рассвет и закат с отдельной настройкой.
- Погода: дождь, лужи, отражения (SSR на «Высоко», пробы на «Средне»), туман, снег, мелкая пыль.
- Декали, GPU-частицы, объёмный свет фар и фонарей в тумане (дешёвый).
- Пост-эффекты: тонмаппинг (AgX или ACES), bloom, LUT по районам и погоде, TAA, SSAO, опциональные зерно, виньетка, motion blur, хроматическая аберрация на ударах.
- FSR, динамическое разрешение; отладочные режимы (wireframe, overdraw, кластеры света, LOD, тайминги проходов).


### 66.6. Конвейер ассетов han_cooker

- Следит за assets_src/ и собирает assets_bin/: меши, скелеты, анимации, текстуры KTX2, звуки, шрифты, ячейки мира.
- Входные форматы: glTF 2.0; FBX и OBJ — через автоматическую конвертацию Blender в фоне (Python-скрипт для Blender CLI); PNG / JPG / TGA, WAV / OGG / MP3, TTF / OTF.
- Автоматически: единые оси и масштаб, ретаргет на мастер-скелет, LOD, коллизии, разрезка на куски для разрушений, сжатие текстур, атласы, проверка лицензий по CREDITS.md.
- Инкрементальная сборка по хэшам, отчёт об ошибках простым языком.


### 66.7. Генератор города han_osm

- Импорт OSM PBF выбранных кварталов, масштабирование по сжатию карты с сохранением топологии.
- Граф дорог и полос (число полос, односторонность, автобусные полосы), перекрёстки, светофоры, переходы, тротуары.
- Здания: контуры + этажность → тип (жилая башня, вилла, офис, магазинный дом, ханок) → фасад из модульного кита, вывески по типу улицы, крыши с баками и кондиционерами.
- Парки, деревья, вода, набережные, мосты; рельеф из SRTM.
- Результат — ячейки мира, которые затем доводятся в редакторе; повторный импорт не затирает ручные правки.


### 66.8. Стриминг мира

- Сетка ячеек 128×128 м: объекты, свет, навмеш, полосы трафика, точки спавна, триггеры.
- Фоновая загрузка по приоритету (направление и скорость игрока), без фризов; интерьеры — отдельные ячейки.
- Бюджеты памяти: выгрузка дальних ячеек и мипов при нехватке.
- Состояние мира (сломанные предметы, машины игрока, территории) — в сохранении.


### 66.9. ИИ, толпа, трафик

- Навмеш (Recast) при сборке ячеек; толпа (DetourCrowd) с LOD: рядом — полный ИИ, средне — упрощённо, далеко — только анимация.
- Расписания жителей и плотность по районам и времени (см. «Живой город»).
- Трафик по графу полос: светофоры, перестроения, пробки, реакция на аварии, курьеры-нарушители, автобусы по маршрутам; дальние машины без физики.
- Восприятие: зрение, слух (драки, сирены), камеры видеонаблюдения, память о событиях.


### 66.10. Встроенный редактор

- F11 (только в разработческой сборке) — редактор внутри игры: расстановка объектов, кисти, дороги, зоны спавна, свет, триггеры миссий, интерьеры.
- Редакторы данных: приёмы (таймлайн с хитбоксами и анимацией), стили и комбо-графы, мини-игры, анимационный граф, база motion matching, одежда, тату, машины (параметры физики с живым тестом), магазины, миссии.
- Секвенсор катсцен. Undo / redo. Владелец балансирует игру без кода.


### 66.11. Сохранения

- Версионированный формат с миграциями, контрольная сумма, резервная копия предыдущего сохранения.
- Автосохранение, быстрое сохранение вне боя, 10 слотов.


### 66.12. Автотесты и самопроверка Claude

- Юнит-тесты: математика, формулы урона, прогрессия, обучение, экономика, сохранения, розыск, парсеры.
- **Headless-режим**: `han_game --scenario combat_1v4 --frames 3600 --report out.json`.
- **Скриншоты**: `--screenshot out.png --at-frame N --camera preset` — проверяй рендер глазами.
- **Бенчмарк-маршрут** по городу с замером 1% low FPS, времени кадра, VRAM.
- Vulkan validation — ноль ошибок в отладочной сборке.
- Сравнение скриншотов «до / после» для регрессий рендера.
