## Часть 51. Всё для полноценной игры

> Системы, без которых игра ощущается незаконченной. Каждая — отдельный пункт плана с критериями.


### 51.1. Прогресс игрока

- **Сохранения**: автосохранение, быстрое, 10 ручных слотов, резервная копия, облако Steam.
- **Перепрохождение миссий** из журнала, с лучшими медалями; **пропуск миссии** после N провалов.
- **Новая игра+**: после титров — сохраняются стили, приёмы, навыки, одежда, машины; враги сильнее, новые вызовы топ-10, «Легенда»-медали.
- **Пост-игра**: защита титула (вызовы), реванши с мастерами, турниры с новыми правилами, 100%.
- **Статистика и достижения** (см. «Экономика в цифрах…»).


### 51.2. Удобство (quality of life)

- Быстрое перемещение: такси (пропустить поездку), метро между станциями, автобус, вызов своей машины.
- Метки на карте, маршрут GPS по клику, авто-маршрут к цели миссии, «показать путь» лентой по земле (опция).
- Старт миссии рядом с прошлой точкой; повтор с чекпоинта мгновенно; пропуск поездок к миссии.
- Пауза в любой момент, в том числе в катсценах; автопауза при сворачивании окна и отключении геймпада.
- Журнал с кратким пересказом «Ранее в HAN» при загрузке после перерыва.
- Смена одежды из телефона дома и в любом магазине, быстрая смена образа (Tab-колесо: 3 избранных образа).


### 51.3. Диалоги, катсцены, озвучка

- **Система диалогов**: узлы реплик, условия (выборы, Честь, отношения), выборы с таймером, реплики во время езды и ходьбы (прерываются и продолжаются, как в GTA V).
- **Инструменты повествования**: редактор диалогового графа, просмотр всех веток, проверка «ничего не потеряно», экспорт текста для вычитки владельцем.
- **Озвучка** — по выбору владельца: (а) только текст + эмоциональные звуки и выдохи; (б) голоса друзей-добровольцев с подписанным согласием; (в) синтез речи с лицензией на коммерческое использование. По умолчанию — (а), система поддерживает все три.
- **Синхронизация губ** — по аудио или по тексту (визем-формы).
- **Катсцены** — секвенсор, переходы без загрузок, пропуск удержанием, субтитры всегда.


### 51.4. Режим режиссёра и повторы

- Запись последних 5 минут игры (детерминированный ввод + ключевые состояния) и ручная запись до 30 минут.
- Редактор: камеры (свободная, привязанная, по рельсам), время, погода, глубина резкости, фильтры, замедление, склейка, музыка с радио, экспорт видео (через кодировщик видеокарты, если доступен).
- Публикация в «Видео» в телефоне — растит славу.


### 51.5. Локализация

- Все тексты — ключи; языки: русский (основной), английский, корейский. Шрифты с хангылем и кириллицей.
- Выгрузка и загрузка таблиц перевода (CSV), проверка длины строк, скриншоты всех экранов на всех языках.
- Корейские надписи города не переводятся (атмосфера), но при наведении в фото-режиме показывается перевод.


### 51.6. Техническая надёжность

- Отчёты о сбоях (минидамп + лог) с согласия игрока; без сбора личных данных.
- Версионирование сохранений с миграциями: патч никогда не ломает сохранения.
- Безопасный режим запуска (низкие настройки) после двух сбоев подряд.
- Горячее подключение геймпадов, корректное Alt+Tab, работа на нескольких мониторах, ультраширокие экраны.
- Встроенный бенчмарк для игроков.


### 51.7. Моды (по желанию, после релиза)

- Данные (JSON), Lua-скрипты и ассеты в открытых форматах; папка mods/ с приоритетами.
- Моды не влияют на достижения, если владелец так решит.


### 51.8. Тестирование

- Автотесты (юнит, сценарии, скриншоты, бенчмарк) — на каждый коммит в разработческой ветке.
- Чек-листы на каждый этап: прохождение всех миссий автопилотом (скриптовые боты), облёт карты, все экраны.
- Плейтесты: владелец и 3–5 друзей играют с записью экрана; Claude разбирает заметки в задачи.
- Трекер задач (например, GitHub Issues): баги с шагами воспроизведения, приоритетами и версией.


### 51.9. Релиз

- Платформа: Steam (Windows). Интеграция: достижения, облачные сохранения, статистика, оверлей.
- Страница игры: описание, 6–10 скриншотов (фото-режим), трейлер (режим режиссёра), системные требования.
- Возрастной рейтинг: заполнить анкету содержания Steam; для продаж в отдельных странах (включая Корею) — проверить требования местных рейтинговых органов.
- Юридически: лицензионное соглашение, титры с лицензиями (CC-BY, ODbL и др.), отсутствие реальных брендов и логотипов, реальные места — без товарных знаков.
- Патчи: журнал изменений, хотфиксы без поломки сохранений, ветка «бета» в Steam для тестов.
