# Результаты доводки по аудиту — 2026-11-02

Исходный аудит: `AUDIT_2026-11-02.md`. Исправления сохранены локальными коммитами, push/PR/слияние не выполнялись. Текущая ветка содержит все изменения; зоны разделены по последовательным веткам и коммитам.

## Что исправлено

| Проблема | Результат |
|---|---|
| Попадание после входа в священную зону | Мост отменяет начатую атаку и буфер при входе нападающего или защитника даже при пустом вводе. Выход обратно требует нового запроса. Оглушение, уклоны и движение сохранены. Добавлены регрессии. |
| Переполнение диапазонов `.hcell` | Проверяются границы без переполнения, кратность треугольникам, последовательное покрытие частей и ссылки на вершины. Повреждённые диапазоны отклоняются при записи и чтении. |
| Обрезание координат `.hcell` | Для расширенной геометрии автоматически выбирается HCL2 с float-позициями, HCL1 остаётся совместимым компактным вариантом. Добавлены круговые проверки больших объектов и высотного рельефа. Мапо заново запечён из локальных исходников. |
| Дополнительные дефекты загрузчика | Проверка длины файла до выделения больших массивов, конечных чисел, фонарей/коллайдеров и лишних байтов. Неудачное чтение не меняет выходные объекты вызывающего. |
| Синхронный стриминг | Чтение/декодирование файлов выполняется в фоне; координаты и размер проверяются, завершения ограничены за кадр, ошибки идут в механизм повторов. Исправлен учёт памяти при синхронном ответе загрузчика. |
| Остановка GPU при удалении меша | Старые буферы удалённых/заменённых мешей освобождаются после завершения использующих их кадров. `releaseMesh`/`replaceMesh` не вызывают `vkDeviceWaitIdle`. |
| Проверка лицензий | Используется классификатор конвейера с проверкой начала названия лицензии. `CC-BY-NC4.0`, `Limited license`, `MITunknown` отклоняются. Лицензии needs-owner требуют совпадающего явного решения в манифесте. Проверяются также заменённые ассеты и кириллические пути. |
| Ложный успех автоматизации | Ошибка сравнения Git завершает проверку лицензий/зон ненулевым кодом; отсутствие роли в `han_zones check` также не считается успехом. Символы статуса заменены на совместимые с cp1251. |
| Пробелы CI | В build добавлен валидатор данных с jsonschema 4.26.0; в repo-check — восемь регрессий инструментов владельца. |
| Незакрытый HTTP-ответ | Тело ответа закрывается при HTTPError и отклонённом перенаправлении; добавлен тест, полный Python-конвейер прошёл со строгой проверкой ResourceWarning. |
| Меню малого окна | На 640×360 три кнопки языка помещаются в строку, меню не перекрывается HUD/подсказками. Регрессия проверяет клики по всем шести кнопкам на ru/ko/en и после изменения размера. |
| Устаревшие графические эталоны | Контрольная сборка исходного рендера воспроизвела то же расхождение noon: 4,012/255. Эталоны #17 не учитывали принятое в #47 освещение. Просмотрены все семь текущих кадров, эталоны обновлены; повторный прогон совпал побайтово. Пороги сравнения и шейдеры не менялись. |
| Статусы готовности | Сводка SOLO больше не выдаёт частичные реализации за закрытые этапы. E5/P1 открыты до полного DoD; техническая реализация и успешные проверки сохранены. Обновлены текущие связи между боем, физикой, группами и миром. Старые записи журнала отмечены как история. |

## Открытые критерии и следующие работы

Обнаруженные ошибки корректности исправлены. Доводка стриминга устранила файловое чтение и глобальное ожидание GPU из соответствующих путей, но не доказывает соблюдение бюджета E9: создание физических стен и загрузка буферов всё ещё выполняются на основном потоке. Открыты очередь передачи GPU, HLOD/clustered-свет и маршрутные замеры времени кадра/памяти. Без измерений нельзя объявлять «60 FPS в городе».

Звук на слух, управление руками и субъективная приёмка боя/езды требуют владельца. Не проверены чистая установка, Debug/VS2022 и удалённые PR/CI. Формальные статусы не заменяют эти проверки.

План ролей: A — движок/мир/город и инфраструктура сборки; B — бой/игрок/анимация/игровые экраны; OWNER — командные инструменты. В SOLO выполняются все роли, сохраняя границы изменений. По текущей сводке дальше: приёмка арены, контракт скиннинга и A1, завершение экранов E8/E8a, вертикальная навигация E11 и игровое обучение G2. Новые механики и весь оставшийся объём игры этим исправлением не объявляются готовыми.
