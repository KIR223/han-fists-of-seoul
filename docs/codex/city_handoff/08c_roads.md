# Этап 08, подэтап 08c — недостающие классы дорог (faf23442)

Ветка `a/faf23442-city-08c-roads` (база — 08b, PR #77). **Этап 08 в целом не закрыт.**

## Проблема

754 линии OSM с классами `highway`, для которых `roadWidth` возвращал 0, не рисовались (этап 01): busway 259, corridor 367, construction 48, track 30, platform 30, elevator 7, raceway 7, road 4, bridleway/bus_stop/abandoned по 1.

## Что сделано

`roadWidth` теперь задаёт ширину для классов, которые реально существуют на местности:

| класс | линий | ширина | замечание |
|---|---|---|---|
| busway | 259 | 3,5 м | выделенные автобусные полосы Сеула, красное покрытие (цвет вершин) |
| track | 30 | 3 м | грунтовые дороги, материал пешеходного покрытия, не асфальт |
| raceway | 7 | 8 м | |
| road | 4 | 5 м | тип не уточнён |

**Не рисуются сознательно:** construction (48, дорога строится, не проезжая), corridor (367) / platform (30) / elevator (7) — внутри зданий и станций (нужны интерьеры), bus_stop (точка), bridleway, abandoned.

Трафик не затронут (проезжими остаются только классы из `driveable()`: busway не включён). Для пешеходов ширина меньше 8 м не закрывает мостовую, raceway (8 м) закрыт.

## Результат

`han_citycook`: дорог 60 558 → **60 858** (+300 — ровно busway + track + raceway + road). Тесты: `city_test` (ширины по классам, нерисуемые остаются 0), все наборы зелёные; аудит прохожих в Хондэ: на проезжей части вне переходов 4 шага из 221 400 (до — 0–24 по районам, в пределах прежнего).

## Ограничения

- **Визуальное сравнение «до/после» не получено.** Кадры демо с `--camera` при разных запечённых каталогах и одинаковых параметрах дали разные позы камеры, поэтому кадры не сопоставимы; проверка опирается на числа и тесты. Красные автобусные полосы на кадре ближнего вида видны только в виде красных площадок у перекрёстка (`build/stage07/r08_busway_b.png`) — недостаточно, чтобы считать вид проверенным.
- Автобусные полосы лежат поверх основной проезжей части на 1,3 см выше (по схеме `lift`): мерцания (z-fighting) на расстоянии не проверялись.
- Не сделано в этапе 08: высотки по реальным ориентирам, дальний вид (HLOD), Кандам/Каннам, сравнительные панорамы с реальными местами, недостающие кварталы вне OSM.
- Город перепечён; старый запек — `assets_bin/city/seoul_pre08c` (в Git не входит).
