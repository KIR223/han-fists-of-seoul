# Этап 07 — материалы городских поверхностей (faf23442)

Ветка `a/faf23442-city-07-materials` (база — ветка этапа 06). **Этап закрыт частично.**

## Находка

Из 17 слотов `citytex::slots()` 12 ссылались на наборы библиотеки владельца (`tx_lib_*`), которых на этой машине нет. До исправления загружалось **4 из 17** слотов, остальные 13 материалов (асфальт, кирпич, штукатурка, бетон, тротуар, трава, металл…) рисовались плоским цветом — на кадре улица была серой плоскостью, фасады без кирпича.

## Сделано

- `Slot::alt` + `resolveFolder()` (`han/render/apps/city_common.h`): если набора библиотеки нет, берётся свободный аналог из уже скачанных CC0-наборов манифеста (`tx_road_asphalt`, `tx_wall_brick_brown`, `tx_wall_plaster_beige`, `tx_wall_concrete`, `tx_sidewalk_brick`, `tx_ground_grass`, `tx_wall_metal_sheet`). Если набор библиотеки есть — используется он, поведение владельца не меняется. Земля (`uploadGround`) использует тот же выбор.
- `han/tools/pipeline/material_inventory.py` — реестр: для каждого слота набор, карты (альбедо/нормаль/шероховатость), размер, мипы, цветовое пространство по `vkFormat`, оценка VRAM, статус (библиотека / свободный аналог / fallback / процедурный). Тест `test_material_inventory.py`.
- Новых ассетов не скачивалось: аналоги уже в манифесте и `docs/credits/A.md`.

## Результат

`material_inventory.py`: слотов 17, **fallback 0**, 14 текстурных слотов — 1024², 11 мипов, альбедо sRGB, нормаль и шероховатость линейные (UNORM), оценка VRAM слотов ≤ 224 МБ (верхняя, RGBA8 без сжатия). Загрузка в демо: 4 → 17 из 17.

Кадры (Хондэ, `--camera 700 2 280 90 0`, 1280×720, Vulkan 0 ошибок): «до» `build/stage07/before_hongdae.png`, «после» `after_hongdae.png`, ночь `after_night.png`, мокро `after_wet.png`, сверху `after_far.png`. Просмотрены: кирпич, плитка, окна на месте, эмиссия вывесок и окон ночью сохранена, мокрый режим даёт более тёмное глянцевое покрытие.

## Не сделано / ограничения

- Это **не** реалистичный корейский набор владельца: один коричневый кирпич служит для трёх слотов (WallBrick/RedBrick/WornBrick), один бетон — для бетона и облицовки, плитка — для тротуара, площади и рельефа. Разнообразие вернётся, когда будет доступна библиотека владельца (`assets_bin/prepared`).
- Нормали: ориентация осей и масштаб рисунка в метрах (высота кирпича) не проверены измерением — только осмотр кадра.
- Вариации/потёки/декали, сжатие BCn (текстуры 1024² без Basis), отдельная проверка Building Set и City 2 — не выполнены.
- «Дождь» — только `--wet`; скачанных наборов для крыш/дерева/стекла отдельно нет (стекло — процедурное).
- Приёмка «100% материалов всех готовых районов» не подтверждена: реестр покрывает слоты города, а не материалы моделей Кандама/интерьеров (нет их данных).
