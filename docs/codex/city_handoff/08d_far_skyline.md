# Этап 08, подэтап 08d — дальний силуэт высоких зданий (faf23442)

Ветка `a/faf23442-city-08d-farview` (база — 08c, PR #78). **Этап 08 в целом не закрыт.**

## Проблема

Стриминг грузит ячейки только в радиусе 900 м; `hlodRadius` (2500 м) в настройках есть, но в рендер не подключён (этап 01). За радиусом зданий нет вообще: на горизонте голая земля, нет «силуэта высоток».

## Что сделано

- `han/world/far_skyline.{h,cpp}`: `buildFarSkyline` строит из OSM грубые коробки (стены + плоская крыша, без окон-деталей) для зданий выше 30 м и с основанием от 120 м². Высоты те же, что у ближнего города (теги → профиль высот 08a → 9 м), рельеф учитывается. Плитки по 512 м (2×2 ячейки).
- `han_city_demo`: плитка рисуется только если **ни одна из её четырёх ячеек не загружена** (нет двойной отрисовки и мерцания), только до 2500 м, без теней (`castsShadow=false`). Флаг `--no-far-skyline` отключает силуэт для сравнения. Силуэт строится при старте из OSM, поэтому нужен `--osm` (в режиме только запечённых ячеек без OSM его нет).
- Тест `far_skyline_test.cpp`: фильтры по высоте и площади, число треугольников, высота крыши, согласованность порядка вершин с нормалями, нормали стен наружу.

## Результат

Реальные данные: 34 269 зданий, 900 плиток, 602 577 треугольников всего. Кадр `build/stage07/far_off.png` (без) и `far_on.png` (с): на горизонте появился плотный силуэт высотных зданий вместо пустой земли.

Стоимость (RTX 5060 Ti, 1280×720, Хондэ, 120 машин, 450 кадров, `--no-vsync`): без силуэта 13,11 мс GPU сцены, 692 вызовов отрисовки, 841 тыс. треугольников; с силуэтом 14,4–14,5 мс (+1,3 мс), 736–802 вызова, 866–889 тыс. треугольников. Для RTX 2050 цифры пересчитать нельзя — замер за владельцем; +1,3 мс из 16,6 — заметная цена, оптимизация (слияние плиток, LOD, радиус) — этап 10.

## Ограничения

- Это грубые коробки с текстурой бетона: без окон-деталей и вывесок, без фасадных вариаций; вблизи зоны загрузки (900–1200 м) при подгрузке ячеек возможна заметная смена силуэт → детальное здание.
- Силуэт не включает здания ниже 30 м; низкая застройка вдали по-прежнему пуста (видно голую землю между ближним городом и силуэтом).
- Нет проверки на реальной RTX 2050; высоты — оценка (профиль 08a).
- Не сделано в этапе 08: высотки по реальным ориентирам, Кандам/Каннам, сравнительные панорамы с реальными местами.
