# Контракты: как зоны разговаривают друг с другом

Контракт — это интерфейс (заголовок C++, схема JSON или Lua-API), через который одна зона пользуется другой. Он лежит в `contracts/`,
у него есть **поставщик** (кто реализует) и **потребители** (кто вызывает). Пока поставщик не готов, потребитель работает с заглушкой.

## Правила
1. Нужна функция у соседа → сначала Issue («Задача для другой зоны»), потом — если это интерфейс — PR в `contracts/` с метками `contract` и `zone-x`.
2. Контракт меняет **поставщик**, но PR одобряют все потребители (GitHub сам требует лишь одного из владельцев строки CODEOWNERS — «одобряют все» это договорённость, следи за ней). Мелкие добавления (новая функция) — без нарушения старых; ломающие изменения — только с планом перехода.
3. В контракте нет логики: только типы, интерфейсы, константы, комментарий «зачем» и пример вызова. Заглушки (`stub`) лежат рядом, в `contracts/stubs/`.
4. Один контракт — один файл (`contracts/<имя>.h` или `.schema.json`). Запись в `contracts/registry.md` обязательна.
5. Не используй чужие внутренности «в обход»: если для вызова нужен `#include "han/render/…"` из чужой зоны — значит, не хватает контракта.

## Как выглядит хороший контракт (шаблон — `contracts/_TEMPLATE.md`)
```cpp
// contracts/combat_events.h — поставщик: B, потребители: A (звук, эффекты, толпа, полиция)
// Зачем: любой удар сообщает миру, что произошло, не зная, кто слушает.
#pragma once
namespace han::contracts {
enum class HitZone { Head, Torso, Legs };
struct HitEvent {
    uint32_t attacker, defender;   // идентификаторы сущностей
    HitZone  zone;
    float    damage, impulse;      // импульс — для физики и звука
    bool     blocked, counter;
};
struct ICombatEventSink { virtual void onHit(const HitEvent&) = 0; virtual ~ICombatEventSink() = default; };
}  // Пример: world.combatEvents().subscribe(&mySink);
```

## Заглушки и параллельная работа
Пока контракт не реализован, потребитель использует заглушку `contracts/stubs/<имя>_stub.h`: она компилируется и возвращает безопасные значения
(пустой результат луча, нулевой импульс). Когда поставщик вливает реальную реализацию, заглушка выключается флагом CMake — ваш код не меняется.
