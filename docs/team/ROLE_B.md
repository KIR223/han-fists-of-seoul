# Роль B — бой, сюжет и игра

Ты отвечаешь за всё, **что игрок делает**: рукопашный бой (главная фишка), обучение приёмам, анимацию и ИИ бойцов — и за игру вокруг боя:
сюжет и миссии, катсцены и озвучку, интерфейс (все экраны), экономику, телефон, стрим, кастомизацию, активности, сохранения, локализацию.
Начинаешь без движка: ядро боя — автономная библиотека с тестами и консольным симулятором, миссии — Lua на моках.

## Что ты даёшь A
События боя (удар, блок, нокдаун, добивание, смерть) — для звука, эффектов, реакций толпы, полиции; API анимации и палитру костей для рендера и толпы;
бойцовые профили NPC (`data/ai`) для уличных драк; скриптовый API `script::bind` (им регистрирует функции A); формат сохранений; ключи локализации.

## Что ты берёшь у A
Физические запросы, контроллер, ввод, звук, движок UI, мировые сервисы, толпа и полиция. Пока их нет — заглушки в `contracts/` и интерфейс `ICombatWorld`.

## Правила роли
- Ядро боя не зависит от рендера и Jolt: всё общение с миром — через `ICombatWorld` из `contracts/`. Бой проверяется тестами и симулятором без движка.
- Всё — данные: приёмы, стили, формулы (`data/combat`), миссии (Lua), диалоги, цены (JSON), тексты (CSV); схемы — в `contracts/schemas/`, валидатор — `python data/_tools/validate_data.py`.
- Каждый приём — с кадрами (startup / active / recovery), окнами отмены, траекторией, стороной, высотой, исходами; для каждого — юнит-тест.
- Миссии проверяются на моках без движка (`data/_tools/mission_sim.lua`): шаги, условия, провалы, награды.
- Реалистичность NPC в драке — части «Как дерутся живые люди» и «Бой в деталях»; 18+ — с настройками интенсивности.
- **Бой на местности (G56)**: склон, грязь, рисовое поле, вода по колено, песок, гравий, отмель, снег и лёд — материал поверхности берёшь из физических запросов A;
  в святых местах (флаг `sacred` от A) атака недоступна. Животные: кабан (уклониться), собаки (отпугнуть).
- Тексты: ru — основной, ko — реплики и вывески, en — вспомогательный; ключи стабильные. Озвучка — по части «Озвучка»; учёт — `VOICE_RIGHTS.md`, `AI_USAGE.md`.
- Событий с участием детей и подростков в контенте нет; храмы — без насилия и насмешек (часть 74).
