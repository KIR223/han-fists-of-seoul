# Команда HAN: как мы работаем вдвоём

Два разработчика, у каждого свой Claude Code. Конфликты не возникают, если выполняются три вещи: **у каждой папки один хозяин, общее лежит в `contracts/`,
сливаем маленькие PR часто**.

| Роль | Кто | Зона | Папки (кратко) | Файл роли |
|---|---|---|---|---|
| **A** | владелец проекта | Движок, рендер, физика, транспорт, карта (город и область), жизнь города (толпа, трафик, полиция, банды), материалы, конвейер ассетов, сборка | `han/core platform render physics audio world ui editor tools ai`, `game/vehicles police gangs`, `data/world city people terrain materials vehicles`, CI | `ROLE_A.md` |
| **B** | друг | Бой, анимация, персонаж, ИИ бойцов + сюжет, миссии, катсцены, озвучка, интерфейс, экономика, телефон, стрим, кастомизация, сохранения, локализация | `han/anim ragdoll cloth script`, `game/combat styles learning minigames player missions stream economy phone customization activities save`, `data/combat ai progress story ui loc audio economy` | `ROLE_B.md` |
| **Владелец** | A | Дизайн-документ, правила, юридическая проверка, приёмка | `docs/design`, `docs/team`, `tools`, `CLAUDE.md` (ветки `o/…`) | — |

Коротко: **A — где происходит игра (мир), B — что игрок делает (бой и игра).**
Точная карта «папка → владелец» — `tools/zones.json`. Проверить: `python tools/han_zones.py who han/render/x.cpp`.

## Порядок работы
1. **Фаза 0 (1–2 дня).** A строит каркас репозитория и первые контракты (E0). B ставит программы и начинает ядро боя (G1) автономно (см. `FIRST_TASKS.md`).
2. **Фаза 1.** Движок A (окно → Vulkan → ассеты → PBR → физика → звук → UI → толпа) растёт параллельно с боем B, а затем с данными, экранами и миссиями B. Стыки — только через `contracts/`.
3. **Фаза 2 — вертикальный срез (G12).** Час игры в Мапо: бокс и кикбоксинг с мини-играми, скутер, полиция, пролог и Акт 1. Общая веха: играют оба.
4. **Фаза 3 — город и акты.** A — остальные районы и жизнь города; B — стили, акты, игровые системы. Параллельно.
5. **Фаза 3б — область вокруг города.** A: рельеф, дороги, вода, материалы (E17–E19), посёлки, деревни, побережье, горы и храмы, общественные места (G51–G55); B: бой на местности (G56),
   побочные истории и занятия за городом.
6. **Фаза 4 — финиш.** Мелочи (G46), оптимизация (E13), юридическая проверка (E15), манифест ассетов (E16), релиз (E14).

Сроки ставьте после первых двух недель, когда будет виден реальный темп. Не жертвуйте качеством.

## Кто решает спорное
Владелец (A). Спорный интерфейс → Issue с меткой `contract`; итог записывается в `contracts/registry.md`. Чтобы решения не были односторонними — перед ломающими
изменениями контракта владелец сначала пишет B в чат и ждёт ответа.

## «Кто за что» для частых вопросов
| Вопрос | Кто |
|---|---|
| Игра тормозит, не хватает памяти | A (общий бюджет), B — свой модуль |
| Приём не «читается», удар не ощущается | B |
| Миссия сломалась | B (скрипт); если прохожие или полиция повели себя странно — A |
| NPC дерётся странно | B |
| Меню, HUD, настройки | B (экраны) + A (движок UI) |
| Машина ведёт себя странно, дыра в карте | A |
| Нужна новая библиотека | Issue для A |
| Лицензия ассета | тот, кто добавляет; проверяет владелец |
