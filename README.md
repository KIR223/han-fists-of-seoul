# HAN: Fists of Seoul (한: 서울의 주먹)

Приватный проект: 3D-игра в открытом мире Сеула с глубокой рукопашной боёвкой. Свой движок HAN Engine (C++20 / Vulkan / Jolt).

## Быстрый старт разработчика
1. Поставь программы: `docs/team/SETUP.md`.
2. `git clone <ссылка>` → в папке проекта положи личные файлы из своего архива (`CLAUDE.local.md`, `.claude/`) или выполни
   `python tools/make_personal.py --role A+OWNER|B` (или просто `python tools/join.py` — роль по логину GitHub).
3. `python tools/setup_local.py` → запусти `claude` → напиши «Начинай». Остальное Claude сделает по `CLAUDE.md`.
